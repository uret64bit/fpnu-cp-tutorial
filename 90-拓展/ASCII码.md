# ASCII 码

> [!abstract] 拓展 · 选读
> 最常用的几个值记住就够：`'0' = 48`，`'A' = 65`，`'a' = 97`。字符题大多靠这几个数做转换。

## 字符本质上是数字

计算机只能存数字，所以每个字符都对应一个编号，这套编号规则就是 ASCII 码。

```cpp
char c = 'A';
printf("%c\n", c);   // A
printf("%d\n", c);   // 65
```

反过来也可以：

```cpp
printf("%c\n", 65);  // A
```

## 常用 ASCII 值

| 字符 | ASCII 值 | 说明 |
| --- | --- | --- |
| `\0` | 0 | 字符串结束符 |
| `\n` | 10 | 换行 |
| 空格 | 32 | 空格 |
| `'0'` | 48 | 数字字符的起点 |
| `'9'` | 57 | 数字字符的终点 |
| `'A'` | 65 | 大写字母起点 |
| `'Z'` | 90 | 大写字母终点 |
| `'a'` | 97 | 小写字母起点 |
| `'z'` | 122 | 小写字母终点 |

由此可得：

```cpp
'9' - '0'   // 9
'z' - 'a'   // 25
'a' - 'A'   // 32
```

## 常见转换

### 数字字符转数字

```cpp
char c = '7';
int x = c - '0';   // 7
```

### 数字转数字字符

```cpp
int x = 7;
char c = x + '0';  // '7'
```

### 大小写转换

```cpp
char lower = 'a';
char upper = lower - 'a' + 'A';  // 'A'

char upper2 = 'A';
char lower2 = upper2 - 'A' + 'a'; // 'a'
```

因为 `'a'` 和 `'A'` 相差 32，也可以直接 `c - 32` / `c + 32`，但用 `-'a' + 'A'` 更清楚。

## 注意事项

- ASCII 只用 0～127 表示常用英文字符、数字和符号；128～255 的扩展编码不是标准 ASCII。
- `char` 是否有符号由编译器决定，存 128～255 的值时可能有差异；算法题通常只处理 ASCII 范围内的字符。
- 中文不是单个 ASCII 字符。UTF-8 编码下，一个汉字通常占 3 个字节，不能用 `char` 简单处理。
- 算法题里的字符串大多是英文、数字和符号，按 ASCII 处理即可。

> [!tip] 竞赛提示
> 遇到字母/数字转换，先想“减 `'0'`、减 `'a'`、减 `'A'`”。这比写一堆 `if` 简洁，也不容易漏情况。
