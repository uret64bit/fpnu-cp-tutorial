# 整数在内存中的表示

> [!abstract] 拓展 · 选读
> 做题时记住结论就够用：`int` 约 $\pm 2.1 \times 10^9$，`long long` 约 $\pm 9.2 \times 10^{18}$。想理解溢出、补码和位运算，再往下看。

## 二进制与位

计算机用 0 和 1 存储数据：

- 1 位（bit）只有 0 或 1 两种状态；
- 8 位组成 1 字节（byte）；
- $n$ 位可以表示 $2^n$ 种不同的组合。

例如 8 位可以表示 $2^8 = 256$ 种状态。

## 无符号数

如果所有位都用来表示数值，就是无符号数：

```text
无符号 8 位：00000000 ～ 11111111
范围：0 ～ 255
```

`unsigned int` 就是无符号整数，只能表示非负值。

## 有符号数与补码

现代计算机用**补码**表示有符号整数。8 位补码的例子：

| 十进制 | 补码 |
| --- | --- |
| 0 | `00000000` |
| 1 | `00000001` |
| 5 | `00000101` |
| -1 | `11111111` |
| -5 | `11111011` |
| 127 | `01111111` |
| -128 | `10000000` |

负数的补码计算方法是：**对应正数按位取反，再加 1**。

以 8 位的 `-5` 为例：

```text
 5      = 00000101
按位取反 = 11111010
加 1    = 11111011
```

所以 `-5` 的 8 位补码是 `11111011`。

> [!warning] 不要理解成“把最高位改成 1”
> 最高位确实可以看作符号位（0 表示非负，1 表示负），但负数的数值不是简单地把最高位改成 1。必须按补码规则计算。

## int 的范围

32 位有符号整数（`int`）的范围是：

```text
-2^31 ～ 2^31 - 1
即 -2147483648 ～ 2147483647
```

大约就是 $-2.1 \times 10^9$ 到 $2.1 \times 10^9$。`long long` 是 64 位，范围约 $\pm 9.2 \times 10^{18}$。

补码让 0 只有一种表示，并且加法和减法可以使用同一套电路，这是它的重要优点。

## 溢出的坑

### 有符号整数溢出

```cpp
int a = 2147483647;
a = a + 1;   // 有符号整数溢出，C++ 标准规定这是未定义行为
```

“未定义行为”意味着标准不保证结果。程序可能得到负数，也可能被优化器做出意想不到的处理。**竞赛代码绝不能依赖有符号整数溢出后的结果。**

### 无符号整数溢出

```cpp
unsigned int x = 4294967295u;
x = x + 1;   // 无符号整数按 2^32 取模，结果是 0
```

无符号溢出是明确定义的，会按 $2^n$ 取模回绕。但竞赛中仍应尽量避免依赖它。

## 竞赛中怎么防溢出

1. 看数据范围：结果可能超过 $2.1 \times 10^9$，就用 `long long`。
2. 乘法前先转换：

```cpp
long long ans = 1LL * a * b;
```

3. 输出 `long long` 用 `%lld`。
4. 取模题也不要掉以轻心：取模前的中间结果仍可能溢出。

## 与位运算的关系

补码让位运算有了很多用途：

```cpp
~0        // -1，所有位都是 1
~a        // 等于 -a - 1
x & 1     // 取最低位，可判断奇偶
```
