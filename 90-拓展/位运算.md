# 位运算

> [!abstract] 拓展 · 选读
> 入门题很少直接用位运算，但它是进阶算法的地基：状态压缩、树状数组、快速幂、子集枚举都会用到。先把运算符和优先级认全。

## 二进制和十六进制

C++14 可以直接写二进制字面量，前缀 `0b`；十六进制用 `0x`：

```cpp
int a = 0b1001;   // 9
int b = 0xFFFF;   // 65535
```

## 六个位运算符

| 运算符 | 名称 | 规则 |
| --- | --- | --- |
| `&` | 按位与 | 两位都是 1 才为 1 |
| `\|` | 按位或 | 有一位是 1 就为 1 |
| `^` | 按位异或 | 两位不同为 1，相同为 0 |
| `~` | 按位取反 | 0 变 1，1 变 0 |
| `<<` | 左移 | 整体左移，低位补 0 |
| `>>` | 右移 | 整体右移 |

### 按位与、或、异或

用 4 位举例（实际 `int` 是 32 位）：

```text
a = 1101   (13)
b = 1011   (11)

a & b = 1001   (9)
a | b = 1111   (15)
a ^ b = 0110   (6)
```

可以用开关面板理解：

- `&`：两个开关都开，灯才亮；
- `|`：任意一个开关开，灯就亮；
- `^`：两个开关状态不同，灯亮。

### 取反

```cpp
int a = 13;   // 二进制 ...00001101
~a;           // -14
```

在 32 位 `int` 中，`~a` 会把所有位取反。因为负数用补码表示，`~a` 的结果等于 `-a - 1`。不要只拿 4 位来理解 `~`，要按类型的实际位数看。

## 移位运算

左移 $k$ 位相当于乘以 $2^k$（在未溢出的前提下）：

```text
3 << 2 = 12      // 0011 -> 1100
```

右移 $k$ 位相当于除以 $2^k$（对非负数）：

```text
16 >> 2 = 4      // 10000 -> 100
```

> [!warning] 移位的坑
> - 左移可能溢出，结果不可靠。
> - 对负数做右移，标准没有规定是补 0 还是补符号位（通常编译器补符号位），**不要依赖**。
> - 移位数不能是负数，也不能大于等于类型宽度，否则是未定义行为。
> - `1 << 31` 中的 `1` 是 `int`，移到符号位附近属于未定义/实现定义行为。需要 32 位时写 `1LL << 31` 或 `1u << 31`。

## 常见用途

```cpp
x & 1          // 判断奇偶：1 是奇数，0 是偶数
x & -x         // lowbit，取出最低位的 1（树状数组会用到）
x >> k         // 右移 k 位
x << k         // 左移 k 位
x ^ y          // 异或，常用于状态翻转/找不同
```

- **状态压缩**：用一个整数的二进制位表示若干个“选/不选”的状态。
- **子集枚举**：`for (int mask = 0; mask < (1 << n); mask++)`。
- **快速幂**：利用二进制拆分指数。

这些应用会在后续专题中展开，入门阶段先认识运算符即可。

## 优先级

位运算符的优先级比很多人想象的低：

```cpp
if (a & b == c) { ... }   // 实际是 a & (b == c)
```

想表达 `(a & b) == c`，必须加括号。移位也比加法低：

```cpp
int x = 1 << 2 + 3;   // 1 << (2 + 3) = 32
```

> 位运算表达式一律加括号。它本身已经不容易读，再靠优先级记忆就是给自己挖坑。优先级总表见 [[运算符优先级]]。
