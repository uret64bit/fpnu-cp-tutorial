## 笔记约定

- **一篇笔记一个概念**，文件名就是概念名（例如 `变量.md`、`if-else条件分支.md`）。
- 每篇开头用 `> [!info] 一句话` 给出核心结论。
- 用双链连接前置知识、相关笔记和练习。
- 竞赛提示统一用 `> [!tip] 竞赛提示`，易错点用 `> [!warning]`。
- **拓展内容**同时带 `#拓展` 标签和 `> [!abstract] 拓展 · 选读` Callout，不阻塞主线学习。
- 未讲到的内容不提前建空笔记，避免死链；路线先写在大纲里。

## 环境约定

| 项目 | 约定 |
| --- | --- |
| 语言 | C++14（兼容 C 风格） |
| 平台 | 洛谷 |
| 输入输出 | 统一用 `scanf` / `printf` |
| 模板 | `#include <bits/stdc++.h>` + `using namespace std;`，见 [[竞赛代码模板]] |
| 提交语言 | C++14 (GCC 9) 或 C++17 |

## 学习方式

```text
看题 → 独立思考 → 写代码 → 自测 → 提交 → 看结果 → 复盘 → 重写
```

遇到报错，先读报错、先自测、先查资料；AI 可以用来解释原因和生成测试数据，但不能代替自己思考。详细建议见 [[学习资源与IDE]]。

## 维护建议

- 新增笔记后，挂到对应索引（MOC）上，避免孤立笔记。
- 修改笔记名时，用 Obsidian 的重命名功能自动更新双链。
- 图片统一放在 `图片/`，用嵌入语法引用。
- 后续讲次按“一句话 + 用法 + 易错点 + 竞赛提示 + 练一练 + 相关笔记”的结构补充。
