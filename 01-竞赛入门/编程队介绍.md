# 编程队介绍

> [!info] 一句话
> 编程队是一个用**算法竞赛**带大家从零学编程、练思维、打比赛的地方。

## 我们学什么

- **语言**：C/C++，课程以 C++14 为主，兼容 C 的写法。
- **内容**：语法 → 基础算法 → 比赛实战。
- **方式**：课上讲思路、现场写代码；课下在 OJ 刷题；定期模拟赛和复盘。
- **方向**：目前以算法教学为主；AI Agent 等应用方向会根据队伍情况逐步展开。

## 你需要投入什么

算法不是听会的，是写会的。建议每周至少保证 **5～8 道题** 的练习量，并且每道题都自己动手提交，不要只看题解。

遇到报错时，先按这个顺序试一遍：

1. 读编译器/评测机给的错误信息；
2. 自己造几组小数据测试；
3. 查资料或问 AI，让对方解释原因；
4. 最后再问学长。

> [!tip] 关于自学
> 课堂只能带你入门，真正的提升来自课后持续刷题和复盘。大学课堂教得浅，不代表你可以学得浅。

## 训练闭环

```text
看题 → 想思路 → 写代码 → 自测 → 提交 → 看结果 → 复盘 → 重写
```

其中最容易偷懒的是“复盘”和“重写”。只提交、不总结，刷再多题也很难进步。
