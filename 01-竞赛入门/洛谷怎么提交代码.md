# 洛谷怎么提交代码

> [!info] 一句话
> 在洛谷提交代码的流程是：进入题目 → 写/粘贴代码 → 选语言 → 自测 → 提交 → 看结果。

## 方法一：使用洛谷在线 IDE

1. 打开题目，点击 **“进入 IDE 模式”**。
2. 在代码框里写完整程序，选择语言 `C++14 (GCC 9)`（C++17 也可以，课程统一用 C++14 写法）。
3. 点击“自测”或样例旁的“运行”，先确认样例能过。
4. 点击“提交”或“提交答案”，等待评测。

## 方法二：本地写好后粘贴

在本地编辑器或 IDE 里写代码，复制到洛谷的提交框即可。注意：

- 粘贴的是**完整程序**，不要带行号；
- 不要带 `freopen`，除非题目明确要求文件输入输出；
- 提交前把调试用的 `printf` 注释掉。

## 提交前检查清单

- [ ] 语言选的是 C++（不要选成 C 却用了 C++ 语法）。
- [ ] 包含了需要的头文件。
- [ ] 输入格式和题目完全一致。
- [ ] 输出没有多余提示语、多余空格或空行。
- [ ] 可能超过 $2 \times 10^9$ 的结果用了 `long long`。
- [ ] 数组大小足够，并且多开了几个位置。
- [ ] 多组数据时，变量和数组已重置。
- [ ] 本地样例通过，边界数据也试过。

> [!tip] 关于 O2 优化
> 洛谷提交界面可以勾选 O2。它会让程序跑得更快，但**不能修复逻辑错误**，也不能依赖未定义行为。初学阶段把 O2 当作加速开关即可。
