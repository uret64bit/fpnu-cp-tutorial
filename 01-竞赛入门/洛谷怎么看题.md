# 洛谷怎么看题

> [!info] 一句话
> 一道题最重要的部分是**输入输出格式、样例和数据范围**，题目背景通常只需要快速扫一眼。

## 找到题目

登录洛谷后，可以在搜索框输入题号，例如 `P1001`；也可以直接访问：

```text
https://www.luogu.com.cn/problem/P1001
```

![[Pasted image 20261015112227.png]]

## 页面从上往下看什么

以 [P1001 A+B Problem](https://www.luogu.com.cn/problem/P1001) 为例：

1. **题号和标题**：`P1001 A+B Problem`。
2. **限制**：时间限制、内存限制，例如 `1.00s / 512MB`。它决定了你的算法大概能有多快、数组能开多大。
3. **题目描述**：题目背景（大多是故事）和真正的任务要求。
4. **输入/输出格式**：每个变量怎么读、结果怎么输出。**这是最重要的部分。**
5. **输入输出样例**：用来验证思路，样例不过的代码一定有错。
6. **说明/数据范围**：数据多大、有没有特殊性质。数组开多大、要不要用 `long long`，都要看这里。

![[Pasted image 20261015113417.png]]

## 读题顺序建议

```text
输入格式 → 输出格式 → 样例 → 数据范围 → 题目描述
```

先弄清楚“程序要接收什么、要吐出什么”，再想算法。很多 WA 不是算法错，而是输入读错、输出多了一个空格。

> [!warning] 样例过了 ≠ 题目过了
> 样例只是公开的几组数据。隐藏测试点会检查边界、特殊情况和大数据。提交后的评测结果才算数。

## 难度标签

洛谷的难度从低到高大致是：入门、普及−、普及/提高−、普及+/提高、提高+/省选−……。

零基础阶段先做 **入门** 和 **普及−**，不要一上来就做提高题。数据范围看不懂没关系，后面学了 [[时间复杂度入门]] 就明白了。
