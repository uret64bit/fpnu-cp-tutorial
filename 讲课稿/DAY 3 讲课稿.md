## 0:00–0:10 开场与快问快答

大家好，欢迎来到 Day 3。前两次课我们内容很多：Day 1 认识了竞赛和 OJ，学了变量、类型、输入输出、运算符和 if 分支；Day 2 学了 switch、三种循环和数组。今天不讲新知识，做三件事：先把重点和易错点串一遍，然后 25 分钟当堂小测，最后讲评、布置复习作业。目标很简单——上课时会做的，考的时候也要能做出来。

先来快问快答热个身。规则：我点名，被点到的人直接答，答不上来可以求助一次。

【提问】8 道快问快答（每题约 1 分钟）：

1. `=` 和 `==` 有什么区别？（答：赋值和判断相等；`if (a = 5)` 是经典错误，永远为真）
2. `7 / 2`、`7 % 2`、`7.0 / 2` 各是多少？（答：3、1、3.5——整数相除结果取整）
3. `int` 最大能存到多少？什么时候必须换 `long long`？（答：约 21 亿；乘积或累加可能超过时，比如 n 是 10 万还要算 n×n）
4. `scanf("%d", &a)` 里为什么要写 `&`？（答：把 a 的地址交给 scanf，它才能把读到的数写进 a）
5. switch 里忘写 `break` 会怎样？（答：贯穿，接着执行下一个 case 直到遇到 break）
6. `break` 和 `continue` 的区别？（答：break 结束整个循环，continue 只跳过本轮进入下一轮）
7. `int a[100];` 合法下标范围是多少？（答：0 到 99；写 a[100] 就越界了）
8. 评测返回 TLE，第一步做什么？（答：看数据范围，估算循环次数，检查是不是嵌套层数太多）

这 8 个问题就是前两次课错误率最高的地方。答错超过 3 个的同学，等会儿复习的时候重点看对应的笔记，页面上都有链接。

## 0:10–0:50 四个模块串讲

### 模块一：判题与读题（约 5 分钟）

先说流程，这是竞赛的基本功。读题三步：看输入格式、看输出要求、看数据范围。数据范围决定两件事——用什么类型，以及你的循环最多能套几层。

再看评测结果，四个字母各对应一个排查方向：CE 是编译错误，直接打开编译信息找行号，通常是分号、括号、拼写；WA 是答案错，先拿样例自测，再想边界情况，比如 0、负数、最大值；TLE 是超时，想复杂度，多半是循环太多层；RE 是运行错误，查数组越界和除以零。

【板书】

```text
读题三步：输入格式 / 输出要求 / 数据范围
排查口诀：CE→编译信息  WA→样例+边界  TLE→复杂度  RE→越界/除零
```

对应笔记：[[评测结果]]、[[洛谷怎么看题]]、[[洛谷怎么提交代码]]。

### 模块二：类型与输入输出（约 10 分钟）

四个类型四个数：`int` 约 21 亿，`long long` 约 9.2×10^18，`double` 15～16 位有效数字，`char` 一个字节存单个字符。

三个高频坑。第一，整数除法：5/2 得 2，小数部分直接砍掉，想要 2.5，至少一个操作数得是 double。第二，溢出：两个 int 相乘，结果还是按 int 存，超过 21 亿就变成负数，所以估算范围很重要。第三，格式符要配对：int 用 `%d`，long long 用 `%lld`，double 用 `%lf`，char 用 `%c`；scanf 里每个变量前面都要 `&`。

【板书】现场敲一遍并运行（用竞赛模板）：

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a; long long b; double c; char ch;
    scanf("%d%lld%lf %c", &a, &b, &c, &ch);
    printf("%d %lld %.2f %c\n", a, b, c, ch);
    return 0;
}
```

【提问】只想输出两位小数，怎么写？（答：`%.2f`）

对应笔记：[[基本数据类型]]、[[printf输出]]、[[scanf输入]]、[[类型转换]]、[[算术运算符]]、[[竞赛代码模板]]。

### 模块三：分支（约 10 分钟）

if-else 和 switch 怎么选，一句话：**相等判断用 switch，区间判断用 if-else**。

switch 三个要点：case 后面必须是整数或字符常量；每个 case 处理完要 break，忘了就贯穿；default 兜底。if-else 重点是边界：题目说"超过 8 小时"，那是 `> 8` 还是 `>= 8`？读题时把等号圈出来。多分支用 else-if 串起来，从高到低或从低到高按顺序排除。

【板书】两种分支的对照例子：

```cpp
// 区间判断 → if-else（成绩分档）
if (s >= 90)      printf("A\n");
else if (s >= 80) printf("B\n");
else              printf("C\n");

// 相等判断 → switch（星期几）
switch (day) {
    case 6: case 7:
        printf("weekend\n");
        break;
    default:
        printf("weekday\n");
}
```

【提问】第一个例子如果去掉所有 else，写成三个独立 if，结果会怎样？（答：90 分也会被判成 B 和 C 档；else 保证了互斥）

对应笔记：[[if-else条件分支]]、[[switch选择语句]]、[[关系运算符]]、[[逻辑运算符]]、[[条件运算符]]、[[运算符优先级]]。

### 模块四：循环与数组（约 15 分钟，重点）

三种循环怎么选：次数明确用 `for`；靠条件停，比如读到 0、数位拆完，用 `while`；`do-while` 先执行再判断，知道就行，竞赛里很少用。

嵌套循环要会算总次数：外层 n 次乘内层 m 次。n 是 10 万，双重循环就是 100 亿次，肯定超时——这就是为什么做题前先看数据范围。

数组是今天的重头戏。四个套路要求**不看笔记能默写**，我现在写一遍，大家跟着抄一遍，小测第三题直接用得上。

【板书】数组四套路 + 倒序输出（逐段写，每写一段讲一句）：

```cpp
int a[100005], n;
scanf("%d", &n);

// 套路1：批量读入
for (int i = 0; i < n; i++) scanf("%d", &a[i]);

// 套路2：求和（sum 用 long long 防溢出）
long long sum = 0;
for (int i = 0; i < n; i++) sum += a[i];

// 套路3：最大值 + 记住位置
int mx = a[0], pos = 0;
for (int i = 1; i < n; i++)
    if (a[i] > mx) { mx = a[i]; pos = i; }

// 套路4：计数（统计 > x 的个数）
int cnt = 0;
for (int i = 0; i < n; i++)
    if (a[i] > x) cnt++;

// 变式：倒序输出
for (int i = n - 1; i >= 0; i--) printf("%d ", a[i]);
printf("\n");
```

【提问】求和为什么用 `long long`？（答：每个数最大 10^9，10^5 个数加起来是 10^14，int 存不下）

倒序输出两个最常见的错：起点写成 `n` 就越界了，应该是 `n - 1`；忘写 `i--` 就死循环了。条件 `i >= 0` 也不能写成 `i > 0`，那样会漏掉第一个元素。

数组开多大：题目说 n 最大 10^5，就开 100005，多留一点余量，全局定义。

对应笔记：[[for循环]]、[[while循环]]、[[do-while循环]]、[[break与continue]]、[[循环嵌套]]、[[数组]]。

## 1:15–1:45 小测讲评

好，停笔。讲评之前先统计一下：三道全 AC 的举手……两题的……一题及以下的同学别灰心，这正是复习课要暴露的问题，错题比新题更有价值。每题先请一位同学说思路，我再写标准代码。

### 讲评 1：P1425 小鱼的游泳时间

【提问】谁来说思路？（期望：把两个时间都换算成分钟，相减，再换回小时和分钟）

这题的核心是**单位换算**。最常见的错误是直接 `c - a` 得小时、`d - b` 得分钟——分钟不够减就出负数了。全部化成分钟，借位问题就自动消失了。算出总分钟后，除以 60 是小时，对 60 取模是分钟，正好用上 Day 1 的整数除法和取模。

【板书】

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a, b, c, d;
    scanf("%d%d%d%d", &a, &b, &c, &d);
    int t = (c * 60 + d) - (a * 60 + b);
    printf("%d %d\n", t / 60, t % 60);
    return 0;
}
```

### 讲评 2：P1085 不高兴的津津

这题是"边读边更新最大值"的套路，不需要数组：循环 7 次，每次读一天上课和补课时间，加起来超过 8 小时、并且比当前记录更长，就更新记录和天数。

两个细节。第一，比较用**严格大于** `>`：题目要求并列时输出最早的一天，所以相等不更新。第二，`day` 初始是 0：津津一周都没有不高兴的时候，正好输出 0，不用特判。

【板书】

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int mx = 0, day = 0;
    for (int i = 1; i <= 7; i++) {
        int a, b;
        scanf("%d%d", &a, &b);
        if (a + b > 8 && a + b > mx) {
            mx = a + b;
            day = i;
        }
    }
    printf("%d\n", day);
    return 0;
}
```

【提问】什么时候就必须用数组了？（答：读完不能马上处理的时候。比如题目改成"输出所有不高兴的天"，或者要先排序、要来回多趟访问）

### 讲评 3：P1427 小鱼的数字游戏

【提问】这题你们用什么类型存的数？为什么？（答：`long long`——数据到 2^32−1，约 42.9 亿，超过 int 的 21 亿上限）

两个考点。第一，"读到 0 为止"：scanf 有返回值，成功读到几个数就返回几；读到 0 就退出循环，0 本身不算。第二，倒序输出：数组存好之后从 `n - 1` 遍历到 `0`——就是刚才板书里写的变式，写错过的同学对号入座。

【板书】

```cpp
#include <bits/stdc++.h>
using namespace std;
long long a[105];
int main() {
    int n = 0;
    while (scanf("%lld", &a[n]) == 1 && a[n] != 0) n++;
    for (int i = n - 1; i >= 0; i--) printf("%lld ", a[i]);
    printf("\n");
    return 0;
}
```

这题数据最多 100 个，数组开 105 就够了——开数组前先看清楚数据范围。
