### Task 14: 新建 `04-算法/动态规划入门.md`

**Files:** Create: `04-算法/动态规划入门.md`

- [ ] **Step 1:** frontmatter：tags `算法`；aliases `DP`、`动态规划`、`数字三角形`。
- [ ] **Step 2:** 一句话：`DP 把大问题拆成重叠子问题，用数组记住答案——关键是状态、转移、边界三件事。`
- [ ] **Step 3:** 正文结构：
  1. `## 三要素`：状态定义、转移方程、初始化/边界。
  2. `## 数字三角形`：
     ```cpp
     for (int i = n; i >= 1; i--)
         for (int j = 1; j <= i; j++)
             dp[i][j] = a[i][j] + max(dp[i + 1][j], dp[i + 1][j + 1]);
     ```
  3. `## 最大子段和`：`dp[i] = max(a[i], dp[i-1] + a[i])`，答案取 `max(dp[i])`。
  4. `## 递归 → 递推`：与 [[递归]] 的对照；记忆化是“递归 + 存答案”。
  5. `> [!warning]`：状态含义没定义清；初始化；遍历顺序依赖前面的状态；答案不一定在 `dp[n]`。
