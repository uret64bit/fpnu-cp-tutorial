### Task 12: 新建 `04-算法/前缀和.md`

**Files:** Create: `04-算法/前缀和.md`

- [ ] **Step 1:** frontmatter：tags `算法`；aliases `前缀和数组`、`区间和`。
- [ ] **Step 2:** 一句话：`前缀和把“每次重新求和”变成“一次预处理 + 一次减法”。`
- [ ] **Step 3:** 正文结构：
  1. `## 暴力与预处理`：m 次区间查询的复杂度对比。
  2. `## 一维前缀和`：1-based 写法；
     ```cpp
     sum[i] = sum[i - 1] + a[i];
     // 区间 [l, r] 的和
     long long ans = sum[r] - sum[l - 1];
     ```
  3. `## 最大子段和`：维护最小前缀 `mn`，答案 `max(sum[i] - mn)`；链 P1115。
  4. `> [!abstract] 拓展 · 选读`：二维前缀和公式 `s[i][j]=s[i-1][j]+s[i][j-1]-s[i-1][j-1]+a[i][j]`，子矩阵和容斥。
- [ ] **Step 4:** `> [!warning]`：1-based 不要越界；答案超 `int` 用 `long long`；`sum[0]=0`。
- [ ] **Step 5:** `> [!tip]`：看到“多次区间求和”先想前缀和；看到“多次区间修改”先想差分。
- [ ] **Step 6:** 练一练：P1115、P5638、P3397（二维）。

- [ ] **Step 2:** 一句话：`差分是前缀和的逆运算：区间加变成两个单点修改，最后扫一遍还原。`
- [ ] **Step 3:** 正文结构：
  1. `## 差分数组`：`d[i] = a[i] - a[i-1]`。
  2. `## 区间加`：
     ```cpp
     d[l] += x;
     d[r + 1] -= x;   // 数组要开到 n + 2
     ```
  3. `## 还原`：对 `d` 做前缀和得到修改后的 `a`。
  4. `## 与前缀和的关系`：加 → 差分，查 → 前缀和。
  5. `> [!abstract] 拓展 · 选读`：二维差分只讲“四个角打标记”的概念，不要求默写。
