### Task 2: 新建 `02-C语言基础/手写排序.md`

frontmatter：tags `[C语言, 算法]`，aliases `[冒泡排序, 选择排序, 插入排序]`

正文结构：
1. 一句话：`冒泡、选择、插入是三种最基础的排序，都是 O(n²)——学它们是为了看懂"排序是怎么回事"；正式比赛一律用 sort。`
2. `## 冒泡排序`：相邻两个比较、大的往右挪；配代码（含提前退出优化）：

```cpp
for (int i = 0; i < n - 1; i++) {
    bool swapped = false;
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
            swapped = true;
        }
    }
    if (!swapped) break;     // 一轮没换过，说明已经有序
}
```

3. `## 选择排序`：每轮找出最小值，和本轮开头交换；配代码（**用下标记录最小值位置**，别用 INT_MIN 之类的值当哨兵）。
4. `## 插入排序`：像理扑克牌，把第 i 张插到前面已经排好的序列里；配代码。
5. `## 稳定性`：相等的元素排完序后相对顺序不变 = 稳定。冒泡、插入稳定；选择不稳定（远距离交换会打乱）。什么时候在意：多关键字排序；竞赛里真正依赖稳定性时直接用 `sort` + 完整 `cmp`。
6. `## 为什么竞赛里还是用 sort`：三者都是 $O(n^2)$；$n = 10^5$ 时约 $10^{10}$ 次操作（几秒到几十秒），`sort` 只要约 1.7×10^6 次。体验任务：把 P1177 用冒泡交一次，看 TLE。
7. `> [!tip] 竞赛提示`：手写排序只在"数据量小 / 需要理解过程 / 题目就是让你写排序"时出现；平时一律 `sort`。
8. 练一练：P1177 冒泡体验；P1116 车厢重组（读懂冒泡在数什么，选做）。
9. 相关笔记：`[[排序]]`、`[[时间复杂度入门]]`、`[[循环嵌套]]`、`[[数组]]`

### Task 6: 新建 `02-C语言基础/二分查找.md`

frontmatter：tags `[C语言, 算法]`，aliases `[二分, lower_bound模板]`

正文结构：
1. 一句话：`二分查找在有序数组里每次丢掉一半——O(log n)，十亿个数只要约 30 次比较。`
2. `## 前提与直觉`：必须先有序（或单调）；每次比较后能确定"答案在哪一半"。
3. `## 手写模板（左闭右开）`：

```cpp
// 返回第一个 >= x 的位置（没有则返回 n）
int lower(int a[], int n, int x) {
    int l = 0, r = n;                // 区间 [l, r)
    while (l < r) {
        int mid = l + (r - l) / 2;   // 等价于 (l + r) / 2，写法更稳
        if (a[mid] >= x) r = mid;    // mid 可能是答案，保留
        else l = mid + 1;            // mid 不可能是答案，跳过
    }
    return l;
}
```

   讲透三点：区间为什么是 `[l, r)`；`r = mid` 与 `l = mid + 1` 的不对称从哪来；循环结束时 `l` 就是答案位置。
4. `## STL 版`：`lower_bound(a, a + n, x) - a`、`upper_bound`（复习 [[STL常用函数]]）。
5. `## 找最后一个 <= x`（变体，选讲一小段）：把数组取反或对称地写，竞赛里更常见的是用 `upper_bound - 1`。
6. `> [!warning] 常见坑`：数组没排序就二分（结果错得离谱）；`l = mid` 死循环；区间写错漏掉端点。
7. 预告：`> [!note] 预告` 二分答案把"求最大/最小"变成"判断可行"，见 [[二分答案]]。
8. 练一练：P2249、P1102、P1678。
9. 相关笔记：`[[STL常用函数]]`、`[[排序]]`、`[[时间复杂度入门]]`、`[[二分答案]]`

### Task 7: 新建 `02-C语言基础/二分答案.md`

frontmatter：tags `[拓展, 算法]`，aliases `[二分求答案, check函数]`；开头 callout 用 `> [!abstract] 拓展 · 选读`

正文结构：
1. 一句话：`答案范围明确、且"猜一个值判断行不行"很容易时——二分答案。`
2. `## 什么时候能用`：题目问"最大的最小值 / 最小的最大值"；check(x) 随 x 单调（x 可行 → 更大/更小也可行）。
3. `## 模板`：

```cpp
// 求最大的可行 x（check(x) 为 true 表示可行）
int l = 0, r = 1000000000, ans = -1;
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) {
        ans = mid;      // 可行，先记下来
        l = mid + 1;    // 试试更大的
    } else {
        r = mid - 1;
    }
}
```

   把 `check` 写成 [[函数]]（单独一个"行不行"的判断函数），逻辑一目了然。
4. `## 两个例子`：P1873 砍树（二分锯片高度：高度越高砍得越少）；P2678 跳石头（二分最短跳跃距离）。
5. `> [!warning] 易错点`：单调方向想反（check 写反）；`l/r` 更新漏 `±1`；中间值超 int 用 `long long`（链 [[整数溢出]]）。
6. 练一练：P1873、P2678。
7. 相关笔记：`[[二分查找]]`、`[[函数]]`、`[[整数溢出]]`、`[[时间复杂度入门]]`
