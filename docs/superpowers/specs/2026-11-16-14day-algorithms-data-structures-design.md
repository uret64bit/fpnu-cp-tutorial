# 14 天基础算法与数据结构课程设计

- 日期：2026-11-16
- 状态：待实施
- 关联：[[教学大纲]]、[[算法索引]]、[[数据结构索引]]、`03-C++基础/`、`04-算法/`、`05-数据结构/`

## 1. 背景

当前笔记库的 Day 1～9 是按实际授课顺序逐步搭建的，存在两个问题：

1. 主题顺序与算法学习顺序不一致：函数/结构体/排序在字符串之前，递归在 STL 之后，复习日占了一个 Day 编号。
2. 算法模块只到二分查找，基础算法（贪心、双指针、前缀和、差分、搜索、DP）和数据结构（链表、堆、并查集、树、图）还没有笔记。

用户要求：

- 把 **Day 1～9 按算法学习的正确顺序重排**。
- 以 **Day 14 为终点**补齐内容，同时覆盖 **基础算法 + 数据结构**。
- 数据结构单独成模块，共 3 天；DFS/BFS 合并 1 天；DP 1 天。

本轮同时承接已构建但未发布的目录重组：`03-C++基础/`（STL）与 `04-算法/`（算法）已迁移完成，将并入第一批发布。

## 2. 目标与非目标

### 目标

- 产出 Day 1～14 共 14 个课程页，按“语言基础 → 基础算法 → 数据结构 → 搜索/DP”的顺序组织。
- 新增基础算法笔记 11 篇、数据结构笔记 5 篇，全部按现有原子笔记模板编写。
- 索引、教学大纲、README 与新的 Day 结构完全一致，无死链、无孤立笔记。
- 保留原 Day 3 复习课内容，转为可选加课，不丢失小测与讲评材料。

### 非目标

- 不新增单调栈/单调队列、哈希表、线段树、树状数组、LCA、最短路等进阶数据结构。
- 不展开 LIS、区间 DP、树形 DP 等 DP 专题（只在 01 背包页做拓展提示）。
- 不修改用户个人文件：`02-C语言基础/第一个C程序.md`、`01-竞赛入门/评测结果.md`、`sdf.md`。
- 不发布 `讲课稿/`。
- 不在本轮调整已有语言笔记的正文，只改课程页、索引和必要交叉链接。
