### Day 5：字符串与二维数组（DAY 5.md + 3 篇）

| 笔记 | 内容要点 |
|---|---|
| `C风格字符串.md` | char 数组与 `\0` 结尾；`scanf("%s", s)` 三个坑（遇空白停、不加 `&`、不查边界要开够大）；读一整行 `fgets(s, sizeof(s), stdin)` + 去掉末尾换行；`strlen`/`strcmp` 知道即可（竞赛尽量用 C++ string）；逐字符处理（`for (int i = 0; s[i]; i++)`）、大小写转换；练 P5704/P5015 |
| `C++字符串.md` | `string` 声明、`size()`、下标、`+` 拼接、`==` 比较、`substr`、逐字符/range-for 遍历、`sort(s.begin(), s.end())`；读入：`cin >> s` / `getline(cin, s)`；**scanf 与 getline 混用的换行坑**（先用 `getchar()` 吃掉换行）；输出 `cout` 或 `printf("%s", s.c_str())`；为什么比 char 数组省事；练 P1308/P1598 |
| `二维数组.md` | 声明 `a[N][M]`、读入与行列遍历、内存估算（`int a[1005][1005]` ≈ 4MB，全局定义防爆栈）、矩阵套路（转置、按行输出、填充类 P5731/P1319）；链 [[数组]]、[[为什么数组下标从0开始]] |

### Day 6：STL（DAY 6.md + 5 篇）

| 笔记 | 内容要点 |
|---|---|
| `vector.md` | 动态数组；`push_back`/`size`/下标/`clear`；遍历（下标 + `for (int x : v)`）；`sort(v.begin(), v.end())`（`begin/end` 只当范围写法记）；与普通数组的取舍；练 P3156/P3613 |
| `pair.md` | `pair<int,int>`、`.first`/`.second`、`make_pair`、自带比较规则（先 first 后 second）可直接 `sort`；什么时候用它、什么时候用结构体；练 P1104 类题 |
| `栈与队列.md` | `stack`：`push`/`pop`/`top`/`empty`，后进先出；`queue`：`push`/`pop`/`front`/`back`/`empty`，先进先出；典型题（括号匹配→栈；模拟排队→队列）；拓展段：`priority_queue`（大根堆，`top` 是最大，后面的最短路用）；练 P1739/P1996 |
| `map与set.md` | `map<string,int>` 下标计数 `mp[s]++`、`count`/`find`、按 key 自动有序；`set` 插入去重自动有序；`unordered_map/unordered_set` 一句带过（更快但不排序）；典型：统计/去重；练 P1059 |
| `STL常用函数.md` | `min`/`max`（两值比较）、`swap`、`abs`、`reverse(a, a+n)`、`unique(a, a+n)`（配 sort 去重）、`lower_bound`/`upper_bound`（有序数组、左闭右开、减首地址得下标）；练 P1059 |
