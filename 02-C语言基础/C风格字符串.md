# C 风格字符串

> [!info] 一句话
> 字符串就是一连串字符，最后跟一个 `\0` 收尾；读单词用 `scanf("%s")`，读一整行要另想办法。

## char 数组与 \0

```cpp
char s[10] = "hello";
```

这行初始化后，`s` 里实际是 6 个位置：`h e l l o \0`。末尾的 `\0`（空字符）是"字符串到此结束"的标记，不算内容。

遍历一个字符串就靠它：

```cpp
for (int i = 0; s[i] != '\0'; i++) {
    // 处理 s[i]
}
```

（也可以简写 `for (int i = 0; s[i]; i++)`——`\0` 的值就是 0，非零即真。）

## scanf("%s", s) 的三个坑

```cpp
char s[105];
scanf("%s", s);
```

- **遇到空格或换行就停**：输入 `hello world` 只会读到 `hello`，读不了带空格的句子；
- **不加 `&`**：`s` 是数组名，本身就是地址；
- **不检查边界**：读到多少它不管，数组必须按题目上限开够（句子最长 100 字符就开 `char s[105]`）。

## 读一整行：fgets

题目说读"一行/一句话"（可能含空格）时，用 `fgets`：

```cpp
char s[100];
fgets(s, sizeof(s), stdin);      // 最多读 sizeof(s)-1 个字符，自动补 '\0'
int len = strlen(s);
if (len > 0 && s[len - 1] == '\n') s[len - 1] = '\0';   // 去掉末尾换行
```

`fgets` 会把行末的换行符也读进来，所以多一步"去掉末尾换行"。用 C++ `string` 有更简单的写法，见 [[C++字符串]]。

## strlen / strcmp：知道即可

- `strlen(s)`：数到 `\0` 为止的字符个数；
- `strcmp(a, b)`：按字典序比较，相等返回 0，`a` 小返回负数，`a` 大返回正数。

> [!warning] 两个 char 数组不能用 == 比较
> `if (a == b)` 比的是两个**地址**，不是内容，永远不为真。要比较内容用 `strcmp(a, b) == 0`——但竞赛里更推荐直接用 C++ `string`，`==` 就能比内容。

## 逐字符处理

```cpp
for (int i = 0; s[i] != '\0'; i++) {
    if (s[i] >= 'A' && s[i] <= 'Z') s[i] = s[i] - 'A' + 'a';   // 大写转小写
}
```

字母的 ASCII 码是连续的（见 [[ASCII码]]），所以"减 32 / 加 32"或者 `tolower`/`toupper` 都能完成大小写转换。

> [!tip] 竞赛提示
> 题目说"一个单词"→ 用 `%s`；说"一行/一句话"→ 用 `fgets`（或 [[C++字符串]] 里的 `getline`）。读入含空格的数据时先用错方法，会读到一半就停，后面的数据全乱。
