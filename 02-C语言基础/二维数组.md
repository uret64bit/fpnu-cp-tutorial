# 二维数组

> [!info] 一句话
> 二维数组就是"一行一行的数组"：`a[i][j]` 表示第 i 行第 j 列，配合双重循环遍历。

## 声明与读入

```cpp
int a[105][105];              // 105 行 × 105 列

for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        scanf("%d", &a[i][j]);
```

把它想成 n 行 m 列的表格：外层循环走"行"，内层循环走"列"。读入格式和题目一一对应——先看题目是"每行 m 个数字"还是"一连串数字按顺序填"。

## 内存估算

```text
int a[1005][1005]   ≈ 4MB      没问题
int a[2005][2005]   ≈ 16MB     可以，但要看内存限制
int a[5005][5005]   ≈ 100MB    多半 MLE
```

开二维数组前按 `行 × 列 × 4 字节` 粗算一遍；**大数组一律定义在 `main` 外面（全局）**——`main` 里的局部数组放在栈上，开大会直接爆栈（见 [[数组]]）。

## 常见套路

- **按行遍历 / 按列遍历**：把内外层循环的 i、j 换一下，就是按列处理；
- **转置**：交换 `a[i][j]` 和 `a[j][i]`——只对 `i < j` 的位置做，避免换两次又换回去；
- **按连续段填充**：读一个数字 x，就按某个方向连续填 x 个格子（P1319 压缩技术、P5731 蛇形方阵都用这个思路）。

## 二维字符数组（存多个字符串）

二维数组装 `char`，就是一个"字符串表"：

```cpp
char s[105][105];                    // 能存 105 个字符串，每个最长 104 个字符
for (int i = 0; i < n; i++)
    scanf("%s", s[i]);               // s[i] 本身就是第 i 个字符串，不加 &
```

`s[i]` 是第 i 个完整的字符串（一整行），`s[i][j]` 是它里面的第 j 个字符——两种用法别搞混。

## 下标从 0 开始

和一维数组一样，行列都从 0 起。题目说"第 i 行第 j 列"（1-based）时，把数组开大一号、统一用 `a[1][1]` 起步，别混着用（为什么从 0 开始，见 [[为什么数组下标从0开始]]）。

> [!tip] 竞赛提示
> 矩阵题的输入格式一定看仔细：按行读的用双重 `scanf`；压缩类（一连串数字）要按连续段填充，别按行列直接读。
