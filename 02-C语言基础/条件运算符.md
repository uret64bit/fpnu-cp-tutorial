# 条件运算符

> [!info] 一句话
> `条件 ? 值1 : 值2`：条件为真取 `值1`，否则取 `值2`。它适合非常短的选择，复杂逻辑还是用 `if-else`。

## 基本用法

```cpp
int max = (a > b) ? a : b;
```

等价于：

```cpp
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

## 常见例子

### 取最大值

```cpp
int max = (a > b) ? a : b;
```

### 取绝对值

```cpp
int abs_value = (x >= 0) ? x : -x;
```

### 根据条件输出不同内容

```cpp
printf("%s\n", (score >= 60) ? "Pass" : "Fail");
```

## 优先级

条件运算符的优先级比较低，高于赋值，低于比较和逻辑运算。通常加括号更清楚：

```cpp
int x = (a > b) ? a : b;
```

如果嵌套，注意结合方向：

```cpp
// 可读性差，不建议这样写
int y = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);
```

多层选择建议用 `if-else if`，逻辑更清晰，也更好调试。

## 易错点

- 两个分支的类型要兼容：一个返回 `int`，另一个返回 `double` 时会做类型转换；初学阶段尽量让两边类型一致。
- 不要为了炫技把条件运算符嵌套很多层。
- 条件运算符不能替代所有 `if`：如果分支里有多个语句，还是用 `if-else`。

> [!tip] 竞赛提示
> 条件运算符适合“一行内做一个简单选择”，比如更新最大值：
> ```cpp
> if (a > max) max = a;
> max = (a > max) ? a : max;  // 前者更易读
> ```
> 可读性优先，不要为了短而牺牲正确性。
