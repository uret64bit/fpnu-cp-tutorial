# 字符与字符串

> [!info] 一句话
> 单引号括起来的是**一个字符**，双引号括起来的是**一串字符**。字符本质上是小整数，字符串则是以 `\0` 结尾的字符数组。

## 字符

```cpp
char c = 'A';
printf("%c\n", c);   // 输出 A
printf("%d\n", c);   // 输出 65（A 的 ASCII 码）
```

`char` 虽然叫“字符型”，但它存储的是字符对应的编码，本质上是一个小整数。字符和数字的对应关系见 [[ASCII码]]。

## 字符串

```cpp
char s[] = "Hello";
printf("%s\n", s);   // 输出 Hello
```

字符串字面量 `"Hello"` 在内存中是：

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

最后的 `\0` 是**空字符**，用来标记字符串结束。`char s[] = "Hello";` 会自动分配 6 个字节。

## 字符的常见运算

```cpp
char c = '7';
int x = c - '0';       // 7，字符 '7' 转成数字 7

char lower = 'a';
char upper = lower - 'a' + 'A';  // 'A'，小写转大写

printf("%c\n", upper);
```

因为 `'0'` 到 `'9'`、`'A'` 到 `'Z'`、`'a'` 到 `'z'` 在 ASCII 表中是连续的，所以可以用加减法做转换。

## 易错点

| 写法 | 含义 | 结果 |
| --- | --- | --- |
| `'A'` | 一个字符 | 占 1 字节，值是 65 |
| `"A"` | 一个字符串 | 占 2 字节：`'A'` 和 `'\0'` |
| `char c = "A";` | 类型不匹配 | 编译错误，字符串不能塞进单个字符 |

- `printf("%c", ...)` 输出字符，`printf("%s", ...)` 输出字符串，`printf("%d", ...)` 输出整数。
- `scanf("%s", s)` 读取字符串时，遇到空格/换行就停止；读一整行要用其他方法，后面会学。
- 中文通常不是单个 `char`，一个汉字在 UTF-8 编码下占多个字节。算法题里的字符串大多是英文/数字。

> [!tip] 竞赛提示
> 字符题优先想“能不能转成数字算”。例如数字字符转整数用 `c - '0'`，字母大小写转换用 `± 32` 或 `-'a' + 'A'`。

> [!note] 预告 · 第 5 讲
> 现在字符串还是"能读能写"的程度，后面会正式学两种：
> - **C 风格字符串**：`char` 数组 + `string.h` 常用函数（`strlen` 长度、`strcmp` 比较、`strcpy` 复制），以及怎么读一整行；
> - **C++ 的 `string`**：用 `+` 拼接、`.size()` 取长度、直接 `==` 比较，还能配合 `sort` 排序，写法比 C 风格省心得多。
>
> 二维字符数组（存多个字符串）也会一起讲。
