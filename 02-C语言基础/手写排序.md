# 手写排序

> [!info] 一句话
> 冒泡、选择、插入是三种最基础的排序，都是 $O(n^2)$——学它们是为了看懂"排序是怎么回事"；正式比赛里一律用 `sort`。

## 冒泡排序

思路：相邻两个比较，大的往右挪；一轮走完，最大的就"冒"到了末尾。

```cpp
for (int i = 0; i < n - 1; i++) {
    bool swapped = false;
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            swap(a[j], a[j + 1]);
            swapped = true;
        }
    }
    if (!swapped) break;     // 一轮没换过，说明已经有序，提前结束
}
```

外层第 i 轮结束时，末尾 i 个元素已经排好，所以内层只需要管前 `n - 1 - i` 个。

## 选择排序

思路：每一轮找出最小值，和本轮开头交换。

```cpp
for (int i = 0; i < n - 1; i++) {
    int minIdx = i;                       // 记录最小值的位置（不是值！）
    for (int j = i + 1; j < n; j++) {
        if (a[j] < a[minIdx]) minIdx = j;
    }
    swap(a[i], a[minIdx]);                // 换到本轮开头
}
```

> [!warning] 记录的是下标
> 找最小值要记录"位置"（`minIdx`），最后和 `a[i]` 交换。直接记录"最小值"会发生"知道最小的数是多少、却不知道它在哪"的尴尬。

## 插入排序

思路：像理扑克牌——前面已经排好，把新来的第 i 张插到合适位置。

```cpp
for (int i = 1; i < n; i++) {
    int key = a[i], j = i - 1;
    while (j >= 0 && a[j] > key) {
        a[j + 1] = a[j];      // 比 key 大的都往右挪一格
        j--;
    }
    a[j + 1] = key;           // key 落到空出来的位置
}
```

## 稳定性

排完序后，**相等元素的相对顺序不变**，就叫"稳定"：

- 冒泡、插入：稳定（只和相邻元素交换，相等时不换）；
- 选择：**不稳定**（远距离交换可能把相等元素的顺序打乱）。

什么时候在意？多关键字排序时：先按次要关键字排一遍，再用稳定排序按主要关键字排——顺序就保住了。竞赛里真依赖稳定性时，直接用 `sort` 写完整 `cmp`（链 [[排序]]）更省心。

## 为什么竞赛里还是用 sort

三种手写排序都是 $O(n^2)$：$n = 10^5$ 时约 $10^{10}$ 次操作，几秒都跑不完；而 `sort` 是 $O(n\log n)$，约 $1.7 \times 10^6$ 次，眨眼就排好（对比见 [[时间复杂度入门]]）。

**体验任务**：把作业里的 P1177 用冒泡交一次，亲眼看一次 TLE——就明白为什么比赛没人手写排序了。

> [!tip] 竞赛提示
> 手写排序只在三种场合出现：数据量很小（$n \le 1000$）、题目就是让你写排序过程、需要理解某个算法的中间步骤。平时解题一律 `sort`。
