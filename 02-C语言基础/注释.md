# 注释

> [!info] 一句话
> 注释是写给人看的说明，编译器会忽略它。好的注释解释“为什么”，而不是重复“代码在做什么”。

## 两种基本注释

```cpp
// 单行注释：从 // 到本行末尾

/*
 * 多行注释：
 * 可以写很多行，
 * 但不能嵌套另一个 /* ... */。
 */
```

合法示例：

```cpp
int a = 10;  // 行尾也可以写注释

/*
 * 下面这三行用来演示多行注释
 */
int b = 20;
```

> [!warning] 多行注释不能嵌套
> `/*` 和 `*/` 只能配对一次。注释里又写 `/* ... */`，编译器会在第一个 `*/` 处结束注释，后面的内容可能变成语法错误。

## 注释写什么

推荐：

```cpp
// 先读入 n，再读入 n 个数
scanf("%d", &n);

// 答案可能超过 int，用 long long
long long sum = 0;
```

不推荐：

```cpp
// 把 a 加 1
a++;
```

“把 a 加 1”看代码就知道；注释应该说明目的、边界或易错点。

> [!abstract] 拓展 · 选读
> 临时屏蔽一大段代码时，可以用预处理指令：
> ```cpp
> #if 0
> printf("调试信息\n");
> // 一些暂时不用的代码
> #endif
> ```
> `#if 0` 到 `#endif` 之间的内容不会参与编译。初学阶段用多行注释也可以，但要记得不能嵌套。

## 竞赛提示

- 提交前把调试用的 `printf` 注释掉或删除，否则可能 WA。
- 注释不会影响运行速度，但不要写太多废话。
- 如果中文注释导致本地编译异常，检查文件是否保存为 UTF-8 编码。
