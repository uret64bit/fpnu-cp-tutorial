# 逻辑运算符

> [!info] 一句话
> `&&` 表示“并且”，`||` 表示“或者”，`!` 表示“不”。它们把多个条件组合成一个条件。

## 三个逻辑运算符

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `&&` | 逻辑与（并且） | `a > 0 && b > 0` | 两个都为真才为真 |
| `\|\|` | 逻辑或（或者） | `a > 0 \|\| b > 0` | 任意一个为真就为真 |
| `!` | 逻辑非（不） | `!flag` | 真变假，假变真 |

真值表（1 表示真，0 表示假）：

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |

## 常见用法

### 判断一个数在区间内

```cpp
if (0 <= x && x <= 10) {
    // x 在 [0, 10] 内
}
```

不能写成 `0 <= x <= 10`，原因见 [[关系运算符]]。

### 判断闰年

```cpp
if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
    printf("是闰年\n");
}
```

### 判断奇偶

```cpp
if (n % 2 == 1) {
    // 奇数
}
```

## 短路求值

`&&` 和 `||` 会“短路”：

- `a && b`：如果 `a` 为假，就不会再计算 `b`；
- `a || b`：如果 `a` 为真，就不会再计算 `b`。

这可以用来避免除零：

```cpp
if (a != 0 && b / a > 1) {
    // 只有 a != 0 时才会计算 b / a
}
```

如果 `a == 0`，后面的 `b / a` 根本不会执行，程序不会崩溃。

## 易错点

- `&&` 和 `||` 的结果是 0 或 1，但它们的操作数可以是任意整数：非 0 视为真。
- 不要把 `&&` 写成 `&`，也不要把 `||` 写成 `|`。`&`、`|` 是位运算，不会短路，含义不同。
- “或者”在 C/C++ 里是**包含式**的：`a || b` 允许两个都为真。日常生活中“要么 A 要么 B”的排斥或，需要额外判断 `a != b`。
- `!` 的优先级较高，`!a && b` 等价于 `(!a) && b`；不确定就加括号。

> [!abstract] 拓展 · 选读
> 逻辑运算满足德摩根定律：
> ```text
> !(a && b) 等价于 (!a) || (!b)
> !(a || b) 等价于 (!a) && (!b)
> ```
> 化简复杂条件时有用，初学阶段了解即可。
