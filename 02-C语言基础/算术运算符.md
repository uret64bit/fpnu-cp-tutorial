# 算术运算符

> [!info] 一句话
> C/C++ 有 `+ - * / %` 五种算术运算。最容易错的是**整数除法**和**取模**：两个整数相除，小数部分会被直接丢掉。

## 五种运算

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `+` | 加 | `15 + 18` → `33` |
| `-` | 减 | `100 - 45` → `55` |
| `*` | 乘 | `12 * 3` → `36` |
| `/` | 除 | `8 / 2` → `4` |
| `%` | 取余（取模） | `10 % 3` → `1` |

## 整数除法

```cpp
7 / 2    // 3，不是 3.5
7 / 4    // 1，不是 1.75
```

两个整数相除，结果仍然是整数，小数部分被**截断**（不是四舍五入）。C++11 起，整数除法向 0 取整：

```cpp
-7 / 2   // -3
```

如果想得到小数，至少让其中一个操作数变成浮点数：

```cpp
printf("%.2f\n", 7.0 / 2);   // 3.50
printf("%.2f\n", 1.0 * 7 / 2); // 3.50
```

## 取模

`a % b` 表示 `a` 除以 `b` 的余数，只适用于整数。

```cpp
10 % 3   // 1
10 % 5   // 0
```

C++11 起，余数的符号和被除数相同：

```cpp
-7 % 2   // -1
7 % -2   // 1
```

> [!warning] 除数为 0
> 整数除以 0（包括 `% 0`）是未定义行为，程序可能直接崩溃（RE）。写代码前先确认除数不为 0。

## 常见用途

```cpp
n % 2          // 奇偶判断：0 是偶数，1 是奇数
n % 10         // 取出个位
n / 10         // 去掉个位
total_minutes / 60   // 转成小时
total_minutes % 60   // 剩下的分钟
```

## 易错点

### 1. 1 / 2 等于 0

```cpp
int a = 1, b = 2;
printf("%d\n", a / b);       // 0
printf("%.2f\n", 1.0 * a / b); // 0.50
```

### 2. 乘法溢出

`int a = 100000;` 时 `a * a` 已超出 `int` 范围，结果不可靠。什么时候会溢出、怎么防，单独成篇：[[整数溢出]]。

### 3. 取模遇到负数

题目要求结果非负时，可以这样处理：

```cpp
int r = a % m;
if (r < 0) r += m;
// 或者写成 (a % m + m) % m
```

> [!abstract] 拓展 · 选读
> `(a % m + m) % m` 是竞赛中常见的写法，用来把负数余数转成非负。先理解“余数可能是负的”即可，不必现在就背公式。

## 运算符优先级

`*`、`/`、`%` 的优先级高于 `+`、`-`，同级从左到右计算。记不住就加括号：

```cpp
int x = (a + b) * c;
```

详细规则见 [[运算符优先级]]。
