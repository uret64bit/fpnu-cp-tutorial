# 运算符优先级

> [!info] 一句话
> 表达式里先算谁、后算谁，由优先级决定。**记不住就加括号**，这是最省事的做法。

## 常用优先级（从高到低）

| 优先级 | 运算符 | 说明 |
| --- | --- | --- |
| 1 | `()` | 括号，最高 |
| 2 | `++` `--` `!` `~` `(类型)` `sizeof` | 单目运算符、自增自减 |
| 3 | `*` `/` `%` | 乘、除、取模 |
| 4 | `+` `-` | 加、减 |
| 5 | `<<` `>>` | 移位 |
| 6 | `<` `<=` `>` `>=` | 关系比较 |
| 7 | `==` `!=` | 相等比较 |
| 8 | `&` | 按位与 |
| 9 | `^` | 按位异或 |
| 10 | `\|` | 按位或 |
| 11 | `&&` | 逻辑与 |
| 12 | `\|\|` | 逻辑或 |
| 13 | `?:` | 条件运算符 |
| 14 | `=` `+=` `-=` 等 | 赋值 |
| 15 | `,` | 逗号，最低 |

同一优先级的运算符，大多数从左到右计算；赋值和条件运算符从右到左。

## 常见陷阱

### 1. `&` 的优先级低于 `==`

```cpp
if (a & b == c) { ... }   // 实际是 a & (b == c)
```

如果本意是 `(a & b) == c`，必须加括号。

### 2. 移位低于加法

```cpp
int x = 1 << 2 + 3;   // 实际是 1 << (2 + 3)，结果是 32
```

如果想先移位，写 `(1 << 2) + 3`。

### 3. 逻辑非与比较

```cpp
if (!a == b) { ... }   // 实际是 (!a) == b
```

这种写法几乎总是想表达别的意思，直接加括号。

### 4. 赋值优先级很低

```cpp
int x = a > b ? a : b;   // 先算条件运算符，再赋值
```

## 竞赛建议

- 不确定优先级时，加括号，不要靠记忆。
- 但也不要加一堆没必要的括号，影响可读性。
- 写复杂条件时，可以拆成几个变量：

```cpp
bool in_range = (0 <= x && x <= 10);
bool is_even = (x % 2 == 0);
if (in_range && is_even) { ... }
```
