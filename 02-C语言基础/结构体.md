# 结构体

> [!info] 一句话
> 结构体把几个不同类型的数据打包成一种新类型，用 `.` 访问成员。

为什么需要打包，见 [[为什么要用结构体]]。

## 定义

```cpp
struct Student {
    char name[20];   // 成员：名字
    int  score;      // 成员：分数
};                   // 千万别忘了这个分号！
```

`struct Student { ... };` 定义了一种**新类型**。定义只描述"长什么样"，不占内存；用它声明变量时才真正分配空间。

## 声明变量与访问成员

```cpp
Student s;                          // 声明一个 Student 变量
s.score = 90;                       // 用 . 访问成员

scanf("%s%d", s.name, &s.score);    // name 是数组，不加 &；score 要加 &
printf("%s %d\n", s.name, s.score);
```

`s.name` 是一个 `char` 数组，数组名本身就是地址，所以 `scanf` 里**不加 `&`**；`s.score` 是普通 `int`，照旧要加 `&`。这一点是初学最常见的坑。

## 初始化

```cpp
Student t = {"Tom", 90};     // 按成员顺序依次赋值
```

## 结构体数组

一条记录用一个变量，一批记录就用**结构体数组**：

```cpp
Student a[1005];
for (int i = 0; i < n; i++) {
    scanf("%s%d", a[i].name, &a[i].score);
}
```

`a[i]` 是第 i 个学生，`a[i].score` 是他的分数。定义在 `main` 外面的全局结构体数组会**自动清零**（和普通数组一样，见 [[数组]]）。

## 配合 typedef

C++ 里 `struct Student { ... };` 之后可以直接写 `Student s;`，不用再带 `struct`。但你在题解和模板里更常见到这种写法：

```cpp
typedef struct Student {
    char name[20];
    int  score;
} Student;
```

两种写法在这里等价，比赛跟着自己的模板走即可。typedef 的完整用法见 [[typedef类型别名]]。

## 整体操作的限制

- **可以**整体赋值：`s2 = s1;` 把所有成员一次复制过去；
- **不能**整体输入输出：`scanf("%s", s)`、`printf("%s", s)` 都不行，要逐字段；
- **不能用 `==` 比较**：`s1 == s2` 编译不过，要逐字段比（写题时通常写成函数或者配合 `cmp`）。

> [!warning] 易错点
> - 定义末尾**忘分号**——报错位置往往在下一行，很迷惑；
> - `scanf` 里 `s.name` 多写了 `&`（数组不用）或 `s.score` 漏了 `&`（普通变量要）；
> - 比较两个结构体写了 `==`，编译不过。
