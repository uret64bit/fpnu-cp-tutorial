# 转义字符

> [!info] 一句话
> 反斜杠 `\` 加上一个字符，可以表示一些“看不见”或“有特殊含义”的字符，比如换行、制表符、引号本身。

## 常用转义字符

| 转义字符 | 含义 | ASCII 值 |
| --- | --- | --- |
| `\n` | 换行 | 10 |
| `\t` | 水平制表符（Tab） | 9 |
| `\r` | 回车 | 13 |
| `\0` | 空字符 | 0 |
| `\\` | 反斜杠本身 | 92 |
| `\'` | 单引号 | 39 |
| `\"` | 双引号 | 34 |
| `\a` | 响铃 | 7 |
| `\b` | 退格 | 8 |

示例：

```cpp
printf("第一行\n第二行\n");
printf("姓名\t分数\n");
printf("C:\\path\\to\\file\n");
printf("他说：\"你好\"\n");
printf("单引号：%c\n", '\'');
```

## 为什么需要转义

下面这样写会出问题：

```cpp
printf("他说："你好"");
```

编译器会把中间的双引号当成字符串结束。正确写法：

```cpp
printf("他说：\"你好\"");
```

反斜杠本身也是特殊字符，想输出一个 `\` 要写两个：

```cpp
printf("\\n 会输出两个字符：反斜杠和 n\n");
```

## printf 里的百分号

`%` 在 `printf` 的格式串里有特殊含义（格式符），想输出百分号要写 `%%`：

```cpp
printf("完成度：100%%\n");   // 输出：完成度：100%
```

这不是反斜杠转义，而是 `printf` 自己的规则。

## `\0` 与字符串

`\0` 是空字符，C 语言用它标记字符串结束：

```cpp
char s[] = "Hi";   // 实际上是 'H' 'i' '\0'
```

因此 `"Hi"` 占 3 个字节，而不是 2 个。字符数组的长度计算和字符串操作都与这个结束符有关。

> [!abstract] 拓展 · 选读
> 还可以用数值表示字符：
> - `\xhh`：十六进制 ASCII，例如 `\x41` 是 `'A'`；
> - `\ddd`：八进制 ASCII，例如 `\101` 是 `'A'`。
>
> ```cpp
> printf("%c %c\n", '\x41', '\101');  // A A
> ```
> 初学阶段知道有这种写法即可，平时直接写 `'A'` 更清楚。

## 易错点

- `\n` 必须写在引号里，写成 `\n` 单独放在代码中不是换行。
- Windows 文本文件的换行常是 `\r\n`，OJ 一般使用 Linux 的 `\n`；提交代码时不用手动处理。
- 不要用中文引号代替英文引号，否则编译错误。
- `\\` 才表示一个反斜杠，`\` 单独出现可能把后面的字符转义掉。
