# 自增自减运算符

> [!info] 一句话
> `i++` 和 `++i` 都是让 `i` 加 1，区别在于**作为表达式使用时返回的是旧值还是新值**。

## 四种写法

```cpp
i++;   // 后置自增：i 加 1
++i;   // 前置自增：i 加 1
i--;   // 后置自减：i 减 1
--i;   // 前置自减：i 减 1
```

如果只是单独一行：

```cpp
i++;
++i;
```

两种写法效果一样，都是 `i = i + 1`。

## 区别在表达式里

```cpp
int i = 5;
int a = i++;   // 先把 i 的旧值 5 赋给 a，再让 i 变成 6
int b = ++i;   // 先让 i 变成 7，再把新值 7 赋给 b

printf("%d %d %d\n", i, a, b);  // 7 5 7
```

记忆方法：

- `i++`：**先用后加**；
- `++i`：**先加后用**。

## 不要在一个表达式里多次修改同一个变量

```cpp
int i = 1;
int x = i++ + ++i;   // 未定义行为，结果不可预测
```

C++ 标准没有规定这种写法的计算顺序。不同的编译器、不同的优化选项可能得到不同结果，OJ 上也可能表现不一致。

> [!warning] 避免未定义行为
> 同一个表达式里，对同一个变量做多次自增/自减，或者既读又改，都是危险的。拆成多条语句：
> ```cpp
> int i = 1;
> int a = i++;
> int b = ++i;
> int x = a + b;
> ```

## 竞赛提示

- `for` 循环里通常写 `i++`，这是最常见、最不容易出错的用法：
  ```cpp
  for (int i = 0; i < n; i++) { ... }
  ```
- 不要为了“写得更短”而把多个自增塞进一个表达式。
- 如果一道题的结果和预想不一致，检查是不是在复杂表达式里用了 `++`/`--`。
