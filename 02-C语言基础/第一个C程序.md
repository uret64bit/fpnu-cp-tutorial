# 第一个 C 程序

> [!info] 一句话
> 一个 C/C++ 程序从 `main` 函数开始执行，`printf` 负责把内容输出到屏幕。

## 最小程序

```cpp
#include <stdio.h>

int main() {
    printf("Hello, world!\n");
    return 0;
}
```

逐行看：

| 代码 | 作用 |
| --- | --- |
| `#include <stdio.h>` | 引入输入输出相关的工具，`printf` 就在这里 |
| `int main()` | 程序的入口，程序从这里开始执行 |
| `{ ... }` | 一对花括号表示一个代码块 |
| `printf("...");` | 把双引号里的内容输出到屏幕 |
| `\n` | 换行符 |
| `return 0;` | 告诉系统程序正常结束；写上是好习惯 |

## 自己改一改

把双引号里的内容换成任意文字，再运行：

```cpp
printf("I am learning C++!\n");
printf("Algorithm contest, here I come.\n");
```

注意：**分号 `;` 是语句结束的标志**，中文分号 `；` 不行。

## 编译和运行

- 在洛谷在线 IDE 里，点击“运行”或“自测”。
- 在本地 IDE 里，先编译再运行；编译失败时看报错信息。
- 文件后缀写 `.cpp`（或 `.c`），用 C++ 编译器编译。

> [!warning] 常见错误
> - 少写分号：`printf("Hello")` → 编译错误。
> - 用了中文引号：`printf(“Hello”);` → 编译错误。
> - 把 `main` 拼成 `mian` → 找不到入口。
> - 直接提交代码片段，而不是完整程序。

## 竞赛提示

- 输出必须和题目要求完全一致；多一个空格都可能导致 WA。
- 样例通过并不代表所有测试点通过，提交后看评测结果。
