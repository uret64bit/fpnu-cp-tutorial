# 赋值运算符

> [!info] 一句话
> `=` 是赋值，不是“等于”。它把右边的值存进左边的变量盒子；判断相等要用 `==`。

## 基本赋值

```cpp
int a = 10;   // 初始化：创建 a 并放入 10
a = 20;       // 赋值：把 a 原来的值改成 20
```

赋值语句从右往左执行：

```cpp
a = b = 0;    // 先把 0 赋给 b，再把 b 的值赋给 a
```

## 复合赋值

```cpp
a += 5;   // 等价于 a = a + 5
a -= 5;   // a = a - 5
a *= 2;   // a = a * 2
a /= 3;   // a = a / 3
a %= 7;   // a = a % 7
```

示例：

```cpp
int a = 5;
a += 3;   // a = 8
a *= 2;   // a = 16
a /= 5;   // a = 3
a %= 2;   // a = 1
```

> [!warning] `=` 和 `==` 不要混
> ```cpp
> if (a = 1) { ... }   // 把 1 赋给 a，条件永远为真
> if (a == 1) { ... }  // 判断 a 是否等于 1
> ```
> 编译器通常会给出警告，但程序仍然可能编译通过，运行时逻辑就错了。

## 赋值表达式也有值

赋值本身是一个表达式，它的值是赋值后左边变量的值：

```cpp
int a, b;
a = (b = 3) + 1;   // b 变成 3，a 变成 4
```

初学阶段不建议在复杂表达式里连续赋值，容易看错。分开写更清楚：

```cpp
b = 3;
a = b + 1;
```
