# 编译错误排查

> [!info] 一句话
> CE（Compile Error）说明代码还没开始运行。先读**第一条**报错，找到行号，改掉最前面的错误，再重新编译。

## 怎么读报错

编译器通常会给出：

```text
main.cpp:5:21: error: expected ';' before 'return'
```

意思是：在 `main.cpp` 第 5 行、第 21 个字符附近，`return` 前面少了一个分号。注意：**报错位置不一定是真正出错的位置**，经常是“上一行少写了分号，下一行才报错”。

## 常见错误

### 1. 少分号

```cpp
int a = 10   // 少 ;
printf("%d\n", a);
```

报错可能出现在 `printf` 那一行，回头检查上一行。

### 2. 中文标点

```cpp
printf("Hello")；   // 中文分号
int a = 1，b = 2;   // 中文逗号
```

把中文的 `；`、`，`、`（`、`）`、`“”` 全部换成英文半角符号。

### 3. 变量名拼错或没声明

```cpp
int sum = 0;
printf("%d\n", summ);   // summ 未声明
```

C/C++ 区分大小写：`Sum`、`sum`、`SUM` 是三个不同的名字。

### 4. 忘记头文件

```cpp
printf("Hello\n");   // 没有 #include <stdio.h>
```

编译可能报 `printf` 未声明。加上：

```cpp
#include <stdio.h>
// 或比赛常用
#include <bits/stdc++.h>
```

### 5. 括号、引号不配对

```cpp
if (a > 0 {
    printf("positive\n");
}
```

数一数左括号和右括号、左引号和右引号是否成对。

### 6. `main` 写错

```cpp
int mian() { ... }   // 拼写错误
```

C/C++ 程序入口是 `main`，不是 `mian`。

### 7. 把 `scanf` 漏 `&` 当成编译错误

```cpp
scanf("%d", a);   // 可能只是警告，能编译通过，但运行时崩溃
```

这不是 CE，而是潜在的 RE 或错误结果。打开编译器的警告选项，能提前发现很多问题。

## 排查顺序

```text
看第一条 error → 看行号 → 检查该行和上一行 → 改一个错误 → 重新编译
```

不要一次性根据所有报错乱改。修掉第一个错误后，后面的报错可能自动消失。

> [!tip] 竞赛提示
> - 本地编译时打开警告：`g++ -std=c++14 -Wall -Wextra`。
> - 把第一条报错和对应代码贴给 AI，请它解释原因，而不是让 AI 直接重写整份代码。
> - 提交前确保代码能在本地完整编译，不要带着红色波浪线提交。
