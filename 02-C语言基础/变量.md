# 变量

> [!info] 一句话
> 变量就像贴了标签的盒子：标签是变量名，盒子里的东西是变量的值，类型决定盒子能装什么。

## 声明、赋值、初始化

```cpp
int a;        // 声明：创建一个叫 a 的 int 盒子
a = 10;       // 赋值：把 10 放进盒子

int b = 20;   // 初始化：创建盒子时直接放入 20
```

- **声明**：告诉编译器“我要用这个名字，它是什么类型”。
- **赋值**：把一个值存进变量。
- **初始化**：在声明的同时给变量一个初始值。

## 命名规则

变量名由字母、数字、下划线组成，并且：

- 不能以数字开头：`1a` 不合法；
- 区分大小写：`sum` 和 `Sum` 是两个变量；
- 不能和关键字重名：`int`、`for`、`return` 等不能当变量名；
- 建议使用有意义的名字：`sum`、`max_value`、`cnt`，比 `a1`、`b2` 更清楚。

> [!tip] 竞赛代码风格
> 变量名可以短，但不要短到看不懂。题解里的 `a`、`b`、`c` 是为了简洁，你自己写时优先保证不写错。

## 一次声明多个变量

```cpp
int x, y, z;
int p = 1, q = 2;
```

注意下面这种写法：

```cpp
int a, b = 0;   // 只有 b 被初始化，a 的值不确定
```

> [!warning] 局部变量不会自动变成 0
> 函数内部定义的局部变量如果没有初始化，它的值是**不确定的**，可能是一个奇怪的数。写题时一定先初始化：
> ```cpp
> int sum = 0;
> int max_value = -1;
> ```
> 全局变量默认初始化为 0，这一点在学数组时会用到。

## 变量的作用域

在 `main` 里定义的变量，只在这个 `{ ... }` 代码块内有效：

```cpp
int main() {
    int a = 1;
    {
        int b = 2;  // b 只在这个内层代码块有效
    }
    // 这里不能用 b
    return 0;
}
```

初学阶段尽量把变量定义在第一次使用的位置附近，减少作用域混乱。

## 竞赛提示

- **多组数据**：每组数据处理前，把累加器、标记数组等重置。
- 变量名不要和题目里的数学符号混淆，比如 `n` 是数量，`m` 是另一个数量。
- 看到“答案可能很大”，先检查变量类型的范围，再决定用 `int` 还是 `long long`。
