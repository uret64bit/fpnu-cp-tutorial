# do-while 循环

> [!info] 一句话
> `do-while` 先执行循环体、再判断条件，**保证至少执行一次**。竞赛里用得很少，知道它的存在即可。

## 基本语法

```cpp
do {
    // 先执行一次
} while (条件);   // 注意：末尾有分号
```

执行顺序：

```text
执行循环体 → 判断条件 →（真）再执行循环体 → 判断条件 → ... →（假）结束
```

和 `while` 的区别只有一点：**第一次执行不判断条件**。

## 例子

```cpp
int x;
do {
    printf("请输入一个正数：");
    scanf("%d", &x);
} while (x <= 0);
```

先问一次，输入不是正数就继续问。这类“先做一次再检查”的场景在 OJ 题目里很少见。

## 和 while 对比

```cpp
// while：可能一次都不执行
while (n > 0) { ... }

// do-while：至少执行一次
do { ... } while (n > 0);
```

当条件一开始就是假的时候，`while` 直接跳过循环体，`do-while` 仍然执行一次。

## 易错点

- **末尾的分号不能忘**：`while (条件);` 少了分号是语法错误。
- 先想想“条件为假时循环体应不应该执行一次”：应该用 `while`；必须执行一次才用 `do-while`。
- 循环体里同样要保证条件最终会变假，否则死循环。

> [!tip] 竞赛提示
> 绝大多数题目用 `for` 或 `while` 就够了。遇到“至少处理一次”的需求时，`do-while` 能少写一点重复代码，但很多题解里更习惯用 `while` 加前置读入，效果一样。
