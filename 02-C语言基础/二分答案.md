# 二分答案

> [!abstract] 拓展 · 选读
> 二分查找的进阶用法：答案范围明确、且"猜一个值判断行不行"很容易时——二分答案。前置：[[二分查找]]、[[函数]]。

> [!info] 一句话
> 求不出来？那就"猜"——把"求最大/最小"变成"判断可行"，答案的可行性与大小单调相关时就能二分。

## 什么时候能用

两个信号：

1. 题目问"**最大的最小值** / **最小的最大值**"这类问题；
2. 猜一个答案 `x`，能轻松判断"x 行不行"（`check(x)`），而且 `check` 的结果**随 x 单调**——比如"x 可行，那么比 x 小的也都可行"。

## 模板

```cpp
// 求最大的可行 x（check(x) 为 true 表示可行）
int l = 0, r = 1000000000, ans = -1;
while (l <= r) {
    int mid = (l + r) / 2;
    if (check(mid)) {
        ans = mid;      // 可行，先记下来
        l = mid + 1;    // 再试试更大的
    } else {
        r = mid - 1;    // 不行，往小了试
    }
}
// 结束时 ans 就是最大的可行值
```

把 `check` 写成独立的 [[函数]]（一行注释说明它判什么），整个逻辑会非常清楚。

## 两个例子

- **P1873 砍树**：二分锯片高度 `h`——`h` 越高砍得越少。`check(h)`：按高度 `h` 伐木，总量是否 ≥ 需求；
- **P2678 跳石头**：二分最短跳跃距离 `d`——`check(d)`：最多移走 M 块石头后，能不能让所有相邻距离都 ≥ `d`。

同一个套路：**枚举答案 → 判断可行 → 二分收缩**。

> [!warning] 易错点
> - 单调方向想反：想清楚"x 可行时，更大的可行还是更小的可行"，再决定更新哪边；
> - `l`、`r` 更新漏掉 `± 1`，容易死循环；
> - 中间值/答案可能超 int：该 `long long` 就 `long long`（见 [[整数溢出]]）。
