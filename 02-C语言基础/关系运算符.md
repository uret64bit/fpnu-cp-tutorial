# 关系运算符

> [!info] 一句话
> 关系运算符用来比较两个值，结果是 `0`（假）或 `1`（真）。

## 六个关系运算符

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `>` | 大于 | `5 > 3` | `1` |
| `<` | 小于 | `5 < 3` | `0` |
| `>=` | 大于等于 | `5 >= 5` | `1` |
| `<=` | 小于等于 | `4 <= 5` | `1` |
| `==` | 等于 | `5 == 5` | `1` |
| `!=` | 不等于 | `5 != 5` | `0` |

```cpp
printf("%d\n", 7 > 3);   // 1
printf("%d\n", 7 < 3);   // 0
printf("%d\n", 4 >= 4);  // 1
printf("%d\n", 4 != 4);  // 0
```

## `=` 和 `==`

这是初学者最常见的错误之一：

```cpp
int a = 1;

if (a = 2) {   // 赋值！把 2 赋给 a，条件值为 2，永远为真
    printf("会执行\n");
}

if (a == 2) {  // 比较！判断 a 是否等于 2
    printf("a 等于 2\n");
}
```

> [!warning] 写条件时多检查一眼
> `if (a = 1)` 通常能编译通过，只是给警告。看到条件里只有一个 `=`，先怀疑自己是不是想写 `==`。

## 不能连着写

数学里可以写 $0 \le x \le 10$，C/C++ 不行：

```cpp
if (0 <= x <= 10) { ... }   // 错！
```

它实际会先算 `0 <= x`，得到 `0` 或 `1`，再判断 `0 <= 1` 或 `1 <= 1`，结果总是真。

正确写法：

```cpp
if (0 <= x && x <= 10) { ... }
```

## 浮点数比较（拓展）

浮点数在计算机里是近似存储的，直接用 `==` 比较两个 `double` 可能得到意外结果：

```cpp
double a = 0.1 + 0.2;
double b = 0.3;
// a 和 b 可能不“完全相等”
```

竞赛中通常用误差范围判断：

```cpp
#include <cmath>

if (fabs(a - b) < 1e-8) {
    // 认为 a 和 b 相等
}
```

输出题目要求的小数位数时，用 `printf("%.2f")` 即可，不要自己用 `==` 判小数。

## 竞赛提示

- 注意边界：`>` 还是 `>=`，`<` 还是 `<=`。题目里的“至少”“不超过”都是提示。
- 比较结果可以当整数用：`int flag = (a > b);`。
- 多个条件组合时，用 [[逻辑运算符]]，不要写出数学式的连比。
