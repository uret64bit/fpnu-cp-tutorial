# 类型转换

> [!info] 一句话
> `(类型)` 强制转换是你**手动**写出来的类型转换：按新类型重新解释这个值，窄化时截断、超出范围时结果不可预期。

> [!info] 相关概念
> 编译器**自动**完成的转换（赋值、运算时悄悄发生）单独成篇：属性和坑都更多，见 [[隐式转换]]。本笔记聚焦你要手动写的**强制转换** `(类型)`。

## 强制转换

用 `(类型)` 明确告诉编译器“我要转成这个类型”：

```cpp
double d = 3.99;
int n = (int)d;       // n = 3，直接截断小数部分
printf("%d\n", n);
```

浮点数转整数是**向零截断**，不是四舍五入：

```cpp
printf("%d\n", (int)3.99);   // 3
printf("%d\n", (int)-3.99);  // -3
```

> [!tip] 常见使用场景
> 1. **除法要小数**：`(double)a / b`（不写就是整数除法，原理见 [[隐式转换]]）
> 2. **大数乘法防溢出**：`(long long)a * b` 或 `1LL * a * b`，转换要在乘法**开始前**完成
> 3. **取整**：别用强转凑四舍五入，用 `round()`、`floor()`，或按题目要求手动加 0.5

## 易错点

- `(double)a / b` 和 `(double)(a / b)` 不一样：前者先转再除，后者先整数除再转。
- `int` 转回较小类型可能截断，例如把很大的 `long long` 赋给 `int`。
- 字符 `'0'` 和数字 `0` 不同；字符转数字要减 `'0'`。
- 浮点数转 `int` 不四舍五入，需要四舍五入时用 `round()` 或手动加 0.5，按题目要求处理。

## 竞赛提示

- 看到除法和分数，先判断题目要整数还是小数。
- 看到大数乘法，先转 `long long`，再计算。
- 输出 `long long` 用 `%lld`，不要用 `%d`。
