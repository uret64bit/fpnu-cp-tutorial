# 类型转换

> [!info] 一句话
> 不同类型一起运算时，编译器会按规则把值“变成同一种类型”。转换方向不对，可能丢精度、溢出，甚至得到完全不同的结果。

## 隐式转换

常见的转换方向：

```text
char / short → int → long long → double
```

例如：

```cpp
int a = 5;
double x = 3.14;
double sum = a + x;   // a 自动转成 double
```

`char` 参与运算时，实际上会转成它的 ASCII 码对应的整数：

```cpp
printf("%d\n", 'A' + 1);  // 66
```

## 强制转换

用 `(类型)` 明确告诉编译器“我要转成这个类型”：

```cpp
double d = 3.99;
int n = (int)d;       // n = 3，直接截断小数部分
printf("%d\n", n);
```

浮点数转整数是**向零截断**，不是四舍五入：

```cpp
printf("%d\n", (int)3.99);   // 3
printf("%d\n", (int)-3.99);  // -3
```

## 整数除法与类型转换

```cpp
int a = 1, b = 2;
printf("%d\n", a / b);          // 0
printf("%.2f\n", (double)a / b); // 0.50
```

如果只用 `a / b`，两个整数会先做整数除法，结果已经是 0，再转 `double` 也救不回来。

## 防溢出：先转再乘

```cpp
int a = 100000, b = 100000;
long long c = (long long)a * b;  // 先把 a 转成 long long
printf("%lld\n", c);
```

也可以写 `1LL * a * b`。关键是**乘法开始之前**至少有一个操作数已经是 `long long`。

> [!abstract] 拓展 · 选读
> 有符号数和无符号数混用，结果可能和你想的完全不同：
> ```cpp
> printf("%d\n", -14 % 7u);
> ```
> `7u` 是 `unsigned int`。运算时 `-14` 会被转换成无符号数（在 32 位平台上是 $2^{32}-14$），再对 7 取余，结果通常是 **4**，而不是 0。
>
> 这里 `%d` 期望 `int`，实际传入 `unsigned int`，严格来说格式不匹配；常见平台会打印 4。避免这种写法：**不要随意混用有符号和无符号**，需要时统一用 `int` / `long long`。

## 易错点

- `(double)a / b` 和 `(double)(a / b)` 不一样：前者先转再除，后者先整数除再转。
- `int` 转回较小类型可能截断，例如把很大的 `long long` 赋给 `int`。
- 字符 `'0'` 和数字 `0` 不同；字符转数字要减 `'0'`。
- 浮点数转 `int` 不四舍五入，需要四舍五入时用 `round()` 或手动加 0.5，按题目要求处理。

## 竞赛提示

- 看到除法和分数，先判断题目要整数还是小数。
- 看到大数乘法，先转 `long long`，再计算。
- 输出 `long long` 用 `%lld`，不要用 `%d`。
