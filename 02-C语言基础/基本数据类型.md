# 基本数据类型

> [!info] 一句话
> 类型决定三件事：变量占多少内存、能表示多大范围、能参与什么运算。竞赛里最常用的是 `int`、`long long`、`double`、`char` 和 `bool`。

## 位与字节

- **位（bit）**：最小单位，只能表示 0 或 1。
- **字节（byte）**：1 字节 = 8 位。
- $n$ 位可以表示 $2^n$ 种不同的组合。例如 2 位可以表示 `00`、`01`、`10`、`11` 四种状态。

## 常用类型表

| 类型 | 典型大小 | 大致范围 | 用途 |
| --- | --- | --- | --- |
| `char` | 1 字节 | 通常 $-128 \sim 127$，或 $0 \sim 255$ | 字符、小整数 |
| `short` | 2 字节 | $-32768 \sim 32767$ | 较少用 |
| `int` | 4 字节 | $-2.1 \times 10^9 \sim 2.1 \times 10^9$ | 最常用的整数 |
| `unsigned int` | 4 字节 | $0 \sim 4.29 \times 10^9$ | 非负整数，慎用 |
| `long long` | 8 字节 | $-9.22 \times 10^{18} \sim 9.22 \times 10^{18}$ | 大整数、防溢出 |
| `unsigned long long` | 8 字节 | $0 \sim 1.84 \times 10^{19}$ | 极大的非负整数 |
| `float` | 4 字节 | 约 6～7 位有效数字 | 精度低，一般不用 |
| `double` | 8 字节 | 约 15～16 位有效数字 | 小数、实数运算 |
| `bool` | 1 字节 | `true` / `false` | 布尔值（C++） |

> [!warning] `long` 的大小不固定
> `long` 在 64 位 Linux 上通常是 8 字节，在 Windows 上通常是 4 字节。算法竞赛中要表示 64 位整数时，统一写 `long long`，不要用 `long`。

## 怎么选类型

1. **整数默认用 `int`**。
2. 结果可能超过约 $2.1 \times 10^9$，改用 `long long`。例如两个 $10^9$ 相乘，答案可能到 $10^{18}$。
3. 小数用 `double`，不要用 `float`（精度太低）。
4. 字符用 `char`，布尔值用 `bool`。
5. 题目要求对 $10^9+7$ 取模时，中间乘法也要用 `long long`，否则还没取模就溢出了。

## 整数溢出

```cpp
int a = 100000;
int b = 100000;
printf("%d\n", a * b);      // 10^10 超出 int 范围，结果不可靠

long long c = 1LL * a * b;  // 先把一个数变成 long long，再做乘法
printf("%lld\n", c);
```

`1LL` 是 `long long` 类型的字面量。`1LL * a` 会先把 `a` 转换成 `long long`，后面的乘法就不会在 `int` 里溢出。

> [!tip] 竞赛提示
> 看到“答案对 $10^9+7$ 取模”或“$a \times b$，$a,b \le 10^9$”，先想 `long long`。输出 `long long` 用 `%lld`，不要用 `%d`。

## sizeof 求占用字节数

```cpp
printf("%zu\n", sizeof(int));        // 4
printf("%zu\n", sizeof(long long));  // 8
```

`sizeof` 是运算符，不是函数。它的返回值类型是 `size_t`，用 `%zu` 输出。
