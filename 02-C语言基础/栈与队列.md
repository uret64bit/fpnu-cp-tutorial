# 栈与队列

> [!info] 一句话
> 栈是"后进先出"（像叠盘子），队列是"先进先出"（像排队）——都是操作被限制一头的容器。

## 栈 stack：后进先出

```cpp
stack<int> st;
st.push(1);          // 1 进栈
st.push(2);          // 2 进栈（在最上面）
st.top();            // 2：看最上面的
st.pop();            // 2 出栈
st.size();           // 1
st.empty();          // 栈空时为 true
```

想象叠盘子：只能从最上面放、从最上面拿。进栈顺序 `1, 2`，出栈顺序就是 `2, 1`。

## 队列 queue：先进先出

```cpp
queue<int> q;
q.push(1);           // 1 进队
q.push(2);           // 2 进队（排在队尾）
q.front();           // 1：看队头
q.pop();             // 1 出队
q.back();            // 2：看队尾
```

想象排队打饭：新来的排到队尾，先来的先打到饭。进队顺序 `1, 2`，出队顺序还是 `1, 2`。

## 什么时候用

- **栈**：括号匹配、后缀表达式求值——"最近的问题先处理"；
- **队列**：模拟排队、一层一层按顺序扩展（BFS）——"先来先处理"。

> [!tip] 竞赛提示
> 栈和队列**不能按下标访问**；`pop()` **不会返回**被删掉的元素——要先 `top()` / `front()` 看一眼，再 `pop()`。这是最常写错的地方。

> [!abstract] 拓展 · 选读
> `priority_queue<int> pq;`：优先队列，每次 `top()` 拿到的都是当前**最大**的元素（内部是大根堆）。现在知道有它即可——最短路、合并果子这类题会用到。
