# scanf 输入

> [!info] 一句话
> `scanf` 按格式从标准输入读数据。除了字符数组，变量前面必须加 `&`（取地址符）。

## 基本用法

```cpp
int a;
scanf("%d", &a);
```

`&a` 表示“变量 a 的地址”，告诉 `scanf` 把读到的数字存到哪里。初学阶段先记住：**普通变量前加 `&`**。

## 读入多个变量

```cpp
int a, b;
scanf("%d%d", &a, &b);
```

输入：

```text
20 30
```

也可以换行输入：

```text
20
30
```

`%d` 会自动跳过空格和换行，所以两种写法都可以。

## 常用格式符

| 数据类型 | 格式符 |
| --- | --- |
| `int` | `%d` |
| `long long` | `%lld` |
| `unsigned int` | `%u` |
| `float` | `%f` |
| `double` | `%lf` |
| `char` | `%c` |
| 字符串（`char` 数组） | `%s` |

> [!warning] `double` 必须用 `%lf` 读
> ```cpp
> double x;
> scanf("%lf", &x);  // 对
> printf("%f\n", x); // 输出用 %f
> ```
> 用 `%f` 读 `double` 会得到错误结果。这是竞赛中非常常见的错误。

## 易错点

### 1. 忘记 `&`

```cpp
int a;
scanf("%d", a);   // 错！可能崩溃或结果错误
scanf("%d", &a);  // 对
```

### 2. `%c` 会读到空格和换行

```cpp
int n;
char c;
scanf("%d", &n);
scanf("%c", &c);   // 可能读到 n 后面的换行
```

如果只想读一个非空白字符，在 `%c` 前加一个空格：

```cpp
scanf(" %c", &c);
```

### 3. 字符串数组不需要 `&`

```cpp
char s[100];
scanf("%s", s);    // 数组名本身就是地址，不需要 &
```

`%s` 会跳过前导空白，读到下一个空白为止；如果需要读带空格的整行，后面会学其他方法。

### 4. 不要在 OJ 里打印输入提示

```cpp
printf("请输入 a 和 b：");  // 会让输出多出内容，导致 WA
scanf("%d%d", &a, &b);
```

提交给 OJ 的程序只输出题目要求的结果。

## 多组数据（拓展）

有些题目会一直读到文件结束，没有明确的组数。可以用 `scanf` 的返回值：

```cpp
int n;
while (scanf("%d", &n) == 1) {
    // 处理这一组数据
}
```

`scanf` 成功读入几个变量就返回几；遇到文件结束返回 `EOF`。初学阶段遇到“多组数据”的题再看这个写法即可。

> [!tip] 竞赛提示
> 输入格式是题目的一部分。先看清楚“第一行一个整数 n，接下来 n 行每行两个整数”这类描述，再决定 `scanf` 写几次、写在哪个循环里。
