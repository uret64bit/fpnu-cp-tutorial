# 数组

> [!info] 一句话
> 数组是一段**连续的内存**，用一个名字加下标访问一批同类型数据。下标从 0 开始，配合 `for` 循环批量处理。

## 声明与初始化

```cpp
int a[5];               // 5 个 int，下标 0 ~ 4
int b[5] = {1, 2, 3};   // b[0]=1, b[1]=2, b[2]=3, 其余自动补 0
int c[] = {10, 20, 30}; // 长度由初始化列表推断，这里是 3
```

数组大小要用常量表达式：

```cpp
const int MAXN = 100005;   // 定义在 main 外面或里面的常量
int a[MAXN];
```

> [!note] 为什么用 const
> 数组长度必须是编译时能确定的常量。写 `int n; scanf("%d", &n); int a[n];` 是变长数组（VLA），不是 C++ 标准，虽然 GCC 支持，但竞赛里不推荐——统一用 `const int MAXN = ...` 开够上限最稳妥。

## 访问和遍历

```cpp
a[0] = 10;              // 写入
printf("%d\n", a[0]);   // 读取

for (int i = 0; i < 5; i++) {
    printf("%d\n", a[i]);
}
```

下标范围是 `0` 到 `长度-1`。为什么从 0 开始，见 [[为什么数组下标从0开始]]。

## 全局数组自动清零

```cpp
int g[100];   // 定义在 main 外面：自动全部初始化为 0

int main() {
    int a[100];   // main 里面：值是垃圾，必须手动初始化
}
```

竞赛里“计数数组”常写成全局数组，天然是全 0 的。

## 三大套路

### 1. 批量读入

```cpp
int n, a[100005];
scanf("%d", &n);
for (int i = 0; i < n; i++) {
    scanf("%d", &a[i]);
}
```

### 2. 求和 / 求最值

```cpp
long long sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}

int max_value = a[0];        // 注意从 a[0] 开始，而不是随便一个数
for (int i = 1; i < n; i++) {
    if (a[i] > max_value) max_value = a[i];
}
```

### 3. 计数

```cpp
int cnt[1005] = {0};   // 下标当作“值”，元素当作“出现次数”
for (int i = 0; i < n; i++) {
    cnt[a[i]]++;
}
```

这个“用数组当下标桶”的技巧后面很多算法都会用到。

## 数组越界

```cpp
int a[5];
a[5] = 10;   // 越界！合法下标只有 0 ~ 4
```

C/C++ **不会检查**下标是否合法。越界可能读到垃圾值、可能破坏其他变量，也可能直接 RE。这是竞赛中最常见的运行时错误之一。

> [!warning] 防越界的习惯
> 1. 数组大小比题目最大值**多开 5～10 个**；
> 2. 循环条件写清楚：n 个元素用 `i < n`，不是 `i <= n`；
> 3. 用 1-based 时数组开 `n + 1` 以上，并保持一致。

## 内存估算

```text
int a[1000000]   ≈ 4MB
int a[100000000] ≈ 400MB   → 在 128MB 限制下会 MLE
```

开数组前先看题目的内存限制和最大数据范围。粗算方法见 [[时间复杂度入门]]。

> [!abstract] 拓展 · 选读
> 非常大的数组建议定义为**全局数组**：全局区空间大且自动清零；`main` 里的局部数组放在栈上，开太大可能直接爆栈（RE）。

## 0-based 还是 1-based

```cpp
// 0-based：下标 0 ~ n-1
for (int i = 0; i < n; i++) { ... }

// 1-based：下标 1 ~ n，a[0] 空着
int a[MAXN];
for (int i = 1; i <= n; i++) {
    scanf("%d", &a[i]);
}
```

题目里“第 i 个”对应 1-based 更直观；学到前缀和、图论后 1-based 还能少写边界判断。**选一种并坚持用**。

> [!note] 预告 · 第 5～7 讲
> 数组还会以三种形态继续登场：
> - **二维数组**（第 5 讲）：矩阵的读入与按行列遍历；
> - **数组当函数参数**（第 6 讲）：把求和、统计写成函数，数组交给函数处理；
> - **结构体数组**（第 7 讲）：每个元素打包多个字段，配合排序解决"排队""奖学金"类问题。
