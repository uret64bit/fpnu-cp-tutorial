# 排序

> [!info] 一句话
> `sort` 一行就能把数组排好序，默认从小到大；给它一个 `cmp`，就能按你定的规则排。

## 基本用法

```cpp
#include <algorithm>         // 竞赛模板的 bits/stdc++.h 已包含

int a[5] = {3, 1, 4, 2, 5};
sort(a, a + 5);              // 1 2 3 4 5
```

注意区间是**左闭右开** `[a, a + n)`：排序 n 个数就写 `a` 和 `a + n`。用 1-based 数组（下标 1 到 n）时写成：

```cpp
sort(a + 1, a + n + 1);      // 排 a[1] 到 a[n]
```

## 为什么不用自己写排序

初学写排序会先学冒泡（两层循环两两交换），但它是 $O(n^2)$：$n = 10^5$ 时大约 $10^{10}$ 次操作，必然超时。`sort` 是 $O(n\log n)$，$10^5$ 的数据眨眼就排完（原理见 [[时间复杂度入门]]）。**竞赛里一律用 `sort`，不用手写冒泡。**

## 降序：自定义 cmp

`sort` 还能接受第三个参数：一个"比较规则"函数（`cmp` 是 compare 的缩写）：

```cpp
bool cmp(int a, int b) {
    return a > b;        // "a 比 b 更该排在前面"
}
sort(a, a + n, cmp);     // 从大到小
```

口诀：**`cmp(a, b)` 返回 `true`，就表示 a 排在 b 前面**。想从小到大写 `return a < b;`，从大到小写 `return a > b;`——不确定时拿两个数（比如 1 和 2）代进去想一遍。

## 按结构体字段排序（多关键字）

`cmp` 的参数换成结构体，就能按字段排序——这正是 [[为什么要用结构体]] 的兑现：

```cpp
bool cmp(Student x, Student y) {
    if (x.score != y.score) return x.score > y.score;  // 总分高的在前
    return x.id < y.id;                                 // 同分，学号小的在前
}
sort(a, a + n, cmp);
```

多关键字就是"一个字段一个字段地比"：先比总分；总分相同再比下一个字段。P1093 奖学金（总分 → 语文 → 学号）就是这么排的。

> [!warning] 易错点
> - `cmp` 必须"严格"：只能用 `<` 或 `>`，写成 `<=` / `>=` 可能乱序，甚至运行时错误；
> - 区间写错：`sort(a, a + n - 1)` 会**漏掉最后一个元素**；
> - `sort` 直接在原数组上排好，**没有返回值**：写完 `sort(a, a + n);` 接着用 `a` 就行，别写 `b = sort(a, a + n);`。

> [!tip] 竞赛提示
> 看到"按××排序，相同时按××排序"，第一反应就是结构体 + `cmp` 逐字段比较；输出前再核对题目要求的格式。
