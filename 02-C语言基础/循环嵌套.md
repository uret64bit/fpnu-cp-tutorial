# 循环嵌套

> [!info] 一句话
> 一个循环里面再写一个循环，就是嵌套循环。常用来枚举数对、输出二维图形、遍历矩阵——**代价是循环次数相乘**。

## 基本形式

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        // 这里会执行 n × m 次
    }
}
```

习惯上外层变量叫 `i`，内层叫 `j`，不要混用。

## 例子：输出三角形

```cpp
for (int i = 1; i <= 5; i++) {       // 第 i 行
    for (int j = 1; j <= i; j++) {   // 第 i 行有 i 个 *
        printf("*");
    }
    printf("\n");
}
```

输出：

```text
*
**
***
****
*****
```

内层循环的上限可以依赖外层变量 `i`，这是输出图形的常见套路。

## 例子：枚举所有数对

```cpp
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        // 枚举所有 (i, j) 数对，且 i < j
    }
}
```

## 复杂度

外层 $n$ 次、内层 $n$ 次，一共约 $n^2$ 次操作，记作 $O(n^2)$。

```text
n = 100     → 约 10^4 次，毫无压力
n = 1000    → 约 10^6 次，没问题
n = 10^5    → 约 10^10 次，几乎必然 TLE
```

所以**先看数据范围，再决定能不能写双重循环**。详细判断方法见 [[时间复杂度入门]]。

> [!warning] 三层循环要警惕
> 三层嵌套是 $O(n^3)$，$n$ 超过几百就可能超时。写完嵌套循环，先估算总执行次数。

## 常见错误

- 内外层变量名写混：内层条件里用了 `i`，更新里用了 `j`。
- 内层循环的变量没有重置：例如内层每次应该从 0 开始，却写成了从上一轮结束的值开始。
- 该用 `n` 的地方写成 `m`，或相反。
- 在 $O(n^2)$ 已经足够的地方写了 $O(n^3)$。

> [!tip] 竞赛提示
> 很多入门题的“暴力解法”就是嵌套循环枚举。先把暴力写对、拿到部分分，再想优化，是比赛里非常实用的策略。
