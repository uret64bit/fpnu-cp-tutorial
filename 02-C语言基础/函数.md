# 函数

> [!info] 一句话
> 函数是把一段代码打包起名字，用的时候"调用"它——重复的逻辑写一次就够。

## 为什么要有函数

想象一道题里要在三个地方判断质数。如果每次都把判断逻辑抄一遍：

- 代码变长，读起来费劲；
- 要改一个细节（比如把 `i * i <= n` 改成 `i <= n / i`），三处都得改，漏一处就出 bug。

把这段逻辑"打包"成一个函数：写一次、起个名字、到处调用——这就是函数存在的意义。

## 定义与调用

```cpp
int add(int a, int b) {   // 返回类型 函数名(参数表)
    return a + b;         // return 把结果交回去
}

int main() {
    int s = add(3, 5);    // 调用：实参 3、5 复制给形参 a、b
    printf("%d\n", s);    // 8
}
```

拆开看这条定义：

- `int`：**返回类型**——函数算出的结果是什么类型；
- `add`：**函数名**，自己起，用动词更清楚（`isPrime`、`getMax`）；
- `(int a, int b)`：**参数表**，函数需要外面"喂"哪些数据进来；
- `{ ... }`：函数体，`return` 把结果交回给调用处。

调用时括号里写的是**实参**（真实的数值，如 3、5）；定义里的 `a`、`b` 是**形参**（占位的名字）。

## 参数与返回值

实参的值会**复制**一份给形参，所以函数里改形参，不影响外面的变量：

```cpp
void change(int x) {
    x = 100;             // 改的是复制进来的副本
}

int main() {
    int n = 1;
    change(n);
    printf("%d\n", n);   // 1：外面的 n 没变
}
```

- 返回类型写 `void` 表示"不返回结果"，这种函数只管做事（比如输出）；
- 返回类型不是 `void`，函数就必须有 `return`，而且返回的值要能转成这个类型。

## 定义的位置

初学阶段统一把函数写在 `main` **前面**——先定义、后使用。`main` 本身也只是最普通的一个函数（见 [[竞赛代码模板]]）。

> [!warning] 函数不能定义在函数里面
> 把 `int f() {...}` 写在 `main` 的花括号里面是**不允许**的（C++ 不支持嵌套定义函数）。要么写在 `main` 前面，要么在 `main` 里面只**调用**别处定义的函数。

## 数组作为函数参数

想让函数处理一整个数组，参数写成"数组 + 长度"：

```cpp
int sum(int a[], int n) {   // 数组和长度必须一起传
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}

int main() {
    int b[4] = {1, 2, 3, 4};
    printf("%d\n", sum(b, 4));   // 10：传数组名和长度
}
```

两个关键点：

1. **长度必须另传**。函数里的 `a[]` 只是一个"入口"，量不出这排数据有几个，题目说几个就把 `n` 传几个；
2. **函数里改 `a[i]`，外面的数组跟着变**。这和普通变量不同——数组传过去的是**首地址**，函数里操作的是同一块内存。

```cpp
void fill(int a[], int n) {
    a[0] = 999;      // 真的改到了外面的数组
}
```

## 常见错误

- 忘写返回类型（只写 `add(int a, int b) {...}`）；
- 有返回值的函数忘了 `return`，或 `return` 的值类型对不上；
- 函数定义写在 `main` 里面（不允许）；
- 调用时实参的个数、类型和定义对不上。

> [!tip] 竞赛提示
> 把重复逻辑抽成函数，题做得越多越省事：`isPrime`（判质数）、`gcd`（最大公约数）、`dis`（两点距离）几乎是人人必备的小工具。写函数前先想清楚"进什么、出什么"。
