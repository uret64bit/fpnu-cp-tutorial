# while 循环

> [!info] 一句话
> `while` 先判断条件再执行循环体，适合**循环次数事先不知道、靠条件停下来的场景**。

## 基本语法

```cpp
while (条件) {
    // 条件为真就执行，每次执行前都会重新判断
}
```

执行顺序：

```text
判断条件 →（真）执行循环体 → 判断条件 → ... →（假）结束
```

## 例子：拆出每一位数字

```cpp
int n;
scanf("%d", &n);

while (n > 0) {
    printf("%d\n", n % 10);  // 当前个位
    n /= 10;                 // 去掉个位
}
```

输入 `123`，输出 `3 2 1`。循环次数由数字位数决定，事先不知道。

## 例子：直到输入 0 结束

```cpp
int x;
while (scanf("%d", &x) == 1 && x != 0) {
    // 处理 x
}
```

或者先读一次、再循环：

```cpp
int x;
scanf("%d", &x);
while (x != 0) {
    // 处理 x
    scanf("%d", &x);   // 读下一个
}
```

## 多组数据直到文件结束

```cpp
int n;
while (scanf("%d", &n) == 1) {
    // 处理这一组数据
}
```

`scanf` 成功读入几个变量就返回几；读到文件末尾返回 `EOF`，条件为假，循环结束。洛谷上这类题一般会说明“读到 EOF”，判题时输入流会自动结束。

## while 还是 for？

| 场景 | 推荐 |
| --- | --- |
| 循环次数明确（n 次、遍历数组） | `for` |
| 次数未知，靠条件停止（数位拆分、读到 0、EOF） | `while` |

两者可以互相转换，选择更清楚的那种写法。

## 常见错误

### 1. 忘记更新循环变量

```cpp
int n = 123;
while (n > 0) {
    printf("%d\n", n % 10);
    // 忘记 n /= 10 → 死循环
}
```

### 2. 条件写反

```cpp
while (n == 0) { ... }   // 本意是 n != 0
```

### 3. 循环变量没初始化

```cpp
int n;          // n 的值不确定！
while (n > 0) { ... }   // 可能一开始就结束，也可能死循环
```

> [!warning] 死循环
> 死循环不一定报错，程序会一直跑直到超时（TLE）。写完检查：循环体里有没有语句能让条件最终变成假？
