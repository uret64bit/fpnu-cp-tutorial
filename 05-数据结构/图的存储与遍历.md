# 图的存储与遍历

> [!info] 一句话
> 图就是“点 + 边”；小图用邻接矩阵，大图用邻接表，遍历用 DFS 或 BFS。

## 图的术语

- **有向图 / 无向图**：边有没有方向。无向边 `u - v` 等价于两条有向边 `u → v`、`v → u`，存图时要加两次。
- **度**：和点相连的边数；有向图分**入度**（指向它的边）和**出度**（从它出发的边）。
- **连通分量**：无向图里能互相走到的点组成一块，一块就是一个连通分量。
- **重边 / 自环**：两点之间有多条边 / 自己连自己。大多数题允许，但要按题意处理。
- **带权图**：边上有代价，存边时多存一个权值。

## 邻接矩阵

开一个二维数组 `g[u][v]`，表示 u 到 v 有没有边（或边权）：

```cpp
int g[N][N];

// 无向边 u - v
g[u][v] = 1;
g[v][u] = 1;

// 带权无向边
g[u][v] = w;
g[v][u] = w;
```

- 判断 `u`、`v` 是否相邻：$O(1)$；
- 遍历一个点的所有邻居：要扫一整行，$O(n)$；
- 空间 $O(n^2)$：$n = 10^5$ 时根本开不下，只适合 $n \le 1000$ 左右的**稠密图**。

## 邻接表

每个点只存自己真正的邻居，常用 `vector` 实现（见 [[vector]]）：

```cpp
vector<int> g[N];

// 无向边
g[u].push_back(v);
g[v].push_back(u);

// 有向边 u → v
g[u].push_back(v);
```

带权时存 `pair<int, int>`（邻居, 边权）：

```cpp
vector<pair<int, int>> g[N];
g[u].push_back({v, w});
```

- 遍历一个点的邻居：与这个点的度数成正比，记作 $O(d)$；
- 空间 $O(n + m)$（$m$ 是边数），适合大图；
- 判断两点是否相邻没那么快，要扫邻居表。

> [!tip] 怎么选
> 先看数据范围：$n \le 1000$ 且边很密、需要快速判断相邻，用邻接矩阵；$n$ 到 $10^5$ 级别，必须用邻接表。绝大多数入门题用邻接表。

## DFS 遍历

DFS（深度优先）一条路走到黑，走不动再回头，用 [[递归]] 实现：

```cpp
bool vis[N];

void dfs(int u) {
    vis[u] = true;
    printf("%d ", u);
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
}
```

从起点 `s` 调用 `dfs(s)`，就能访问到所有与 `s` 连通（有向图里是“可达”）的点。

## BFS 遍历

BFS（广度优先）一层一层扩展，用 [[栈与队列]] 的队列：

```cpp
bool vis[N];
queue<int> q;

vis[s] = true;          // 入队时立刻标记
q.push(s);
while (!q.empty()) {
    int u = q.front();
    q.pop();
    printf("%d ", u);
    for (int v : g[u]) {
        if (!vis[v]) {
            vis[v] = true;   // 入队时就标记，防止重复入队
            q.push(v);
        }
    }
}
```

**标记时机**：BFS 必须在**入队时**标记；如果等出队才标记，同一个点会被多次入队。DFS 在进入时标记即可。

## 遍历顺序

邻接表里邻居的顺序就是 `push_back` 的顺序。如果题目要求“按编号从小到大”遍历（如 P5318），先把每个点的邻居排序：

```cpp
for (int u = 1; u <= n; u++) {
    sort(g[u].begin(), g[u].end());
}
```

然后再 DFS/BFS，输出的顺序就符合要求。

> [!warning] 易错点
> - **无向图只加了一条边**：`g[u].push_back(v)` 之后忘了 `g[v].push_back(u)`。
> - **重复访问**：DFS/BFS 漏写 `vis`，有环时直接死循环。
> - **BFS 标记太晚**：在出队时才标记，会导致同一个点多次入队，甚至 MLE。
> - **编号从 0 还是 1 开始**：读题，数组开够。
> - **邻接矩阵开太大**：$n = 10^5$ 的 `int g[N][N]` 会直接爆内存。

> [!tip] 竞赛提示
> 图上遍历本身不难，难在**建模**：把状态抽象成点，把一步操作抽象成边。比如迷宫、倒水、电梯都可以看成图。求“能不能到/连通块”用 DFS 或 BFS 都行；求“最少几步”必须 BFS，见 [[BFS搜索]]。图的遍历是 [[DFS搜索]]、[[BFS搜索]] 的基础，入门练习 P5318。
