# 堆与优先队列

> [!info] 一句话
> 堆是一棵“父结点总比孩子小/大”的完全二叉树，优先队列就是它的 STL 版本：每次取出当前最值。

## 堆的性质

堆是一棵**完全二叉树**，并且满足堆序：

- **大根堆**：每个父结点都 ≥ 它的孩子，根就是整个堆的最大值；
- **小根堆**：每个父结点都 ≤ 它的孩子，根就是整个堆的最小值。

完全二叉树可以按层放进数组，下标关系很简单（1-based）：

```text
父结点 i 的孩子：2*i、2*i+1
孩子 i 的父亲：i/2
```

常用操作：

| 操作 | 复杂度 | 说明 |
| --- | --- | --- |
| 取最值 `top()` | $O(1)$ | 就是根 |
| 插入 `push(x)` | $O(\log n)$ | 放到末尾再上浮 |
| 删除最值 `pop()` | $O(\log n)$ | 根与末尾交换，再下沉 |

堆只保证“根是最值”，**不保证整体有序**。要连续取出所有最值，就反复 `top()` + `pop()`，总代价 $O(n \log n)$。

## priority_queue 用法

```cpp
priority_queue<int> pq;                              // 大根堆（默认）
priority_queue<int, vector<int>, greater<int>> q;    // 小根堆

pq.push(3);
pq.push(1);
pq.push(5);
pq.top();     // 5：当前最大值
pq.pop();     // 删除 5；pop 不返回被删的元素
pq.top();     // 3

printf("%d\n", (int)pq.size());
if (pq.empty()) { /* 堆空 */ }
```

> [!warning] `pop()` 不返回值
> `pq.pop()` 只是删除堆顶。想拿到被删的值，必须**先 `top()` 再看，再 `pop()`**。这和 [[栈与队列]] 的 `pop()` 一样，是最常见的丢分点。

## 自定义比较

当元素是结构体时，要告诉优先队列“谁更大”。可以给结构体重载 `operator<`：

```cpp
struct Node {
    int dis, id;
    bool operator<(const Node &b) const {
        return dis < b.dis;   // 默认大根堆：dis 大的优先
    }
};
priority_queue<Node> pq;
```

也可以单独写一个比较结构体，用 `operator()`：

```cpp
struct Node { int dis, id; };

struct Cmp {
    bool operator()(const Node &a, const Node &b) const {
        return a.dis > b.dis;   // 注意是 >：小根堆
    }
};
priority_queue<Node, vector<Node>, Cmp> pq;   // dis 小的在堆顶
```

比较方向很容易写反，记一句：**优先队列的比较返回 `true` 表示 a 排在 b 的后面**（a 的优先级更低）。不确定就用一组数试 `top()`。

## 典型应用

- **合并果子（P1090）**：每次取最小的两堆合并，把和放回；用一个小根堆。
- **动态维护最值**：数据一边插入、一边要随时取最大/最小，堆的复杂度最合适。
- **模板题 P3378**：插入、取最小值、删除最小值。

> [!abstract] 拓展 · 选读
> **手写堆**：理解 `up`（上浮）和 `down`（下沉）就够了，竞赛里直接用 `priority_queue`。
>
> ```cpp
> int h[N], sz;
>
> void up(int i) {
>     while (i > 1 && h[i] < h[i / 2]) {
>         swap(h[i], h[i / 2]);
>         i /= 2;
>     }
> }
>
> void down(int i) {
>     while (i * 2 <= sz) {
>         int j = i * 2;
>         if (j + 1 <= sz && h[j + 1] < h[j]) j++;   // 选更小的孩子
>         if (h[i] <= h[j]) break;
>         swap(h[i], h[j]);
>         i = j;
>     }
> }
>
> void push(int x) { h[++sz] = x; up(sz); }
> void pop() { h[1] = h[sz--]; down(1); }
> ```
>
> 从空堆逐个 `push` 建堆是 $O(n \log n)$；把整个数组直接 `down`，从 $n/2$ 到 1 处理一遍，可以做到 $O(n)$。

> [!warning] 易错点
> - 默认是**大根堆**，要小根堆必须写全 `priority_queue<int, vector<int>, greater<int>>`。
> - `pop()` 不返回元素，先 `top()` 再 `pop()`。
> - 自定义比较的方向写反，导致最大/最小颠倒。
> - 堆空时调用 `top()` 或 `pop()` 是未定义行为，先判 `empty()`。
> - 堆只能快速取**最值**，不能快速找第 k 小或任意元素。

> [!tip] 竞赛提示
> 看到“每次取最小/最大，同时还会动态插入新元素”，先想优先队列。合并果子、哈夫曼编码、多路归并、最短路（Dijkstra 的堆优化）都是同一个套路。数据范围不大时，也可以每次排序代替堆，但复杂度会多一个 $\log$。
