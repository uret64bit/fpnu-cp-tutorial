# 并查集

> [!info] 一句话
> 并查集维护“谁和谁在一个集合里”：find 找代表元，union 合并两个集合，路径压缩让查询接近 O(1)。

## 要解决什么问题

有一堆元素，不断告诉你“x 和 y 是一伙的”，同时不断问“x 和 y 是不是一伙的”。如果每次合并都去改整张表，复杂度会很高。并查集只维护一棵棵**代表树**：

- 每个集合选一个**代表元**（根结点）；
- 同一个集合里的元素，顺着父指针往上走，最终都走到同一个根；
- 判断两个人是不是一伙，就看 `find(x) == find(y)`。

## father 数组

```cpp
int fa[N];   // fa[i] 表示 i 的父亲；根结点的父亲就是自己
```

初始时每个元素各自是一个集合，`fa[i] = i`。合并两个集合，就是把一棵树的根挂到另一棵树的根下面。

## 模板

```cpp
int fa[N];

void init(int n) {
    for (int i = 1; i <= n; i++) fa[i] = i;
}

int find(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);   // 路径压缩
}

void unite(int x, int y) {
    fa[find(x)] = find(y);        // 把 x 的根挂到 y 的根下面
}

bool same(int x, int y) {
    return find(x) == find(y);
}
```

`find` 里的 `fa[x] = find(fa[x])` 就是**路径压缩**：查询过程中把沿途每个结点直接挂到根上，之后再查就快得多。

## 连通块计数

如果题目问“最后还剩几个集合/连通块”，可以在合并时维护计数：

```cpp
int cnt;

void init(int n) {
    for (int i = 1; i <= n; i++) fa[i] = i;
    cnt = n;                       // 一开始 n 个集合
}

void unite(int x, int y) {
    x = find(x);
    y = find(y);
    if (x == y) return;            // 已经在同一个集合
    fa[x] = y;
    cnt--;                         // 成功合并一次，集合数减一
}
```

每次**成功**合并才 `cnt--`，重复合并同一对元素不会多减。

## 按大小合并（可选）

如果总是把高的树挂到矮的树下面，树可能退化成一条链。用一个 `sz` 数组记录集合大小，**把小的挂到大的下面**：

```cpp
int fa[N], sz[N];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
        sz[i] = 1;
    }
}

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

void unite(int x, int y) {
    x = find(x);
    y = find(y);
    if (x == y) return;
    if (sz[x] > sz[y]) swap(x, y);   // 保证 x 是较小的集合
    fa[x] = y;
    sz[y] += sz[x];
}
```

路径压缩 + 按大小合并后，单次操作的均摊复杂度接近 $O(1)$（准确地说是反阿克曼函数，竞赛中当常数看即可）。

> [!warning] 易错点
> - **忘记初始化**：`fa[i] = i` 漏了，`find` 会乱走。
> - **`find` 不写路径压缩**：数据巧的时候会退化成 $O(n)$ 一条链，直接 TLE。
> - **合并方向写反**：`fa[find(x)] = find(y)` 是把 x 挂到 y 下面，别写成 `find(x) = find(y)`（编译都过不了）。
> - **多组数据不重置**：每组数据开头都要重新 `init(n)`。
> - **拿 `fa[x]` 当根**：根要用 `find(x)` 求，`fa[x]` 可能只是中间结点。

> [!tip] 竞赛提示
> 看到“朋友的朋友也是朋友”“判断是否连通”“合并两个集合”“数连通块”，先想并查集。并查集只支持**合并**，不支持分裂；如果题目要删边，通常倒着做或换别的方法（如 [[图的存储与遍历]]）。入门题：P1551、P1536。
