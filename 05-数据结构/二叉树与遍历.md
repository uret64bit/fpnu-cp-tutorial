# 二叉树与遍历

> [!info] 一句话
> 二叉树每个结点最多两个孩子；前/中/后序是“根什么时候访问”，层序是“一层一层访问”。

## 树的术语

- **根**：最上面的结点；**叶子**：没有孩子的结点；
- **深度**：从根到该结点的边数（有的教材按结点数算，差 1，看题目定义）；
- **子树**：以某个结点为根的那一部分；
- **二叉树**：每个结点最多两个孩子，分别叫左孩子、右孩子。

```text
        A
       / \
      B   C
     / \   \
    D   E   F
```

这棵树的前序是 `A B D E C F`，中序是 `D B E A C F`，后序是 `D E B F C A`，层序是 `A B C D E F`。

## 二叉树的存储

竞赛里常用**下标 + 左右孩子数组**，不用指针：

```cpp
int lc[N], rc[N], val[N];   // val 存结点信息
int root;                   // 根结点编号
```

也可以把三个字段打包成结构体（见 [[结构体]]）：

```cpp
struct Node {
    int l, r;
} t[N];
```

题目给字符结点时（如 `A B C` 表示 A 的左孩子 B、右孩子 C），把字符映射成下标，或者直接用 `char lc[N], rc[N]`。空孩子用一个特殊值表示，比如 `0` 或 `'*'`，**全程统一**。

## 三种递归遍历

“前/中/后”说的是**根在什么时候访问**，左右子树的相对顺序始终是先左后右：

| 遍历 | 顺序 | 用途 |
| --- | --- | --- |
| 前序 | 根 → 左 → 右 | 复制树、输出前缀表达式 |
| 中序 | 左 → 根 → 右 | 二叉搜索树中序有序 |
| 后序 | 左 → 右 → 根 | 释放树、计算子树答案 |

递归框架几乎一样：

```cpp
void pre(int u) {
    if (u == 0) return;           // 空结点返回
    printf("%d ", val[u]);        // 根
    pre(lc[u]);                   // 左
    pre(rc[u]);                   // 右
}

void in(int u) {
    if (u == 0) return;
    in(lc[u]);                    // 左
    printf("%d ", val[u]);        // 根
    in(rc[u]);                    // 右
}

void post(int u) {
    if (u == 0) return;
    post(lc[u]);                  // 左
    post(rc[u]);                  // 右
    printf("%d ", val[u]);        // 根
}
```

只要把“访问根”这一行挪到不同位置，就是三种遍历。递归的基础见 [[递归]]。

## 层序遍历

层序用 [[栈与队列]] 的队列：根先入队，每次取出队头，把它的左右孩子依次入队：

```cpp
queue<int> q;
q.push(root);
while (!q.empty()) {
    int u = q.front();
    q.pop();
    printf("%d ", val[u]);
    if (lc[u] != 0) q.push(lc[u]);
    if (rc[u] != 0) q.push(rc[u]);
}
```

如果题目要求**按层分行输出**，在每层开始前记下当前队列大小：

```cpp
while (!q.empty()) {
    int len = q.size();           // 这一层的结点数
    for (int i = 0; i < len; i++) {
        int u = q.front();
        q.pop();
        printf("%d ", val[u]);
        if (lc[u]) q.push(lc[u]);
        if (rc[u]) q.push(rc[u]);
    }
    printf("\n");
}
```

## 由遍历序列还原

已知**中序 + 前序**或**中序 + 后序**，可以唯一确定一棵二叉树；只给前序 + 后序则不行。

思路都是：先从前序/后序找到根，再在中序里找到根的位置，把区间切成左子树和右子树，递归处理。

以 P1030（给中序、后序，求前序）为例：

```cpp
string in, post;

void build(int l, int r, int pl, int pr) {
    if (l > r) return;
    char root = post[pr];              // 后序的最后一个就是根
    printf("%c", root);                // 先序：先输出根
    int k = in.find(root);             // 根在中序中的位置
    int len = k - l;                   // 左子树大小
    build(l, k - 1, pl, pl + len - 1);       // 左子树
    build(k + 1, r, pl + len, pr - 1);       // 右子树
}
```

`build(0, n - 1, 0, n - 1)` 即可输出前序。这里只是“找到根就输出”，不需要真的把树建出来。

> [!warning] 易错点
> - **空结点不返回**：递归边界 `if (u == 0) return;` 漏写会死递归。
> - **字符与下标混用**：题目给的是字符，别拿 `'A'` 直接当下标。
> - **左右写反**：三种遍历的左右顺序永远是先左后右，只有根的位置变。
> - **层序不记录层长**：想按层输出却只用一个普通队列，所有层会混在一起。
> - **切区间长度算错**：左子树大小是 `k - l`，后序左区间是 `[pl, pl + len - 1]`。

> [!tip] 竞赛提示
> 做树题先画图，把“根、左、右”三个位置标出来，再写递归。输入是字符时先确认 `*` 还是 `.` 表示空；多组数据要把数组清空。入门题：P1305 新二叉树（建树 + 前序）、P1030 求先序排列（中序 + 后序）。
