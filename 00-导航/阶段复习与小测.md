# 阶段复习与小测（加课）

> [!info] 本页说明
> 本页承接原 Day 3 的复习课，用于 Day 1～7 的阶段性复习与当堂小测，**不占 DAY 编号**。两小时授课流程与逐字稿仍在本地 `讲课稿/DAY 3 讲课稿.md`（讲师用，不发布）。

## 学习目标（复习课以“能做到”为准）

- 能快速说出 CE / WA / TLE / RE 的排查方向。
- 能讲清整数除法、溢出、`=` 与 `==`、数组越界四个高频坑。
- 不看笔记能写出数组四套路：批量读入、求和、最值、计数，外加倒序输出。
- 能在 25 分钟内独立完成 2～3 道入门题。

## 复习路线一：判题与读题（Day 1）

- [ ] [[评测结果]]：AC / WA / CE / TLE / MLE / RE 各代表什么、第一步查什么
- [ ] [[洛谷怎么看题]]：读题三步——输入格式、输出要求、**数据范围**
- [ ] [[洛谷怎么提交代码]]：自测样例 → 提交 → 看结果

## 复习路线二：类型与输入输出（Day 1）

- [ ] [[基本数据类型]]：`int` 约 21 亿；`long long`、`double`、`char` 什么时候用
- [ ] [[printf输出]] / [[scanf输入]]：`%d` `%lld` `%lf` `%c` 对应关系；`&` 别丢
- [ ] [[算术运算符]] / [[类型转换]]：`7/2=3`、`7%2=1`、`7.0/2=3.5`

## 复习路线三：分支、循环与数组（Day 2）

- [ ] [[关系运算符]] / [[逻辑运算符]]：`=` 与 `==`；`&&` `||` 短路
- [ ] [[if-else条件分支]] / [[switch选择语句]]：区间判断用 if，相等判断用 switch；`break` 别忘
- [ ] [[for循环]] / [[while循环]] / [[do-while循环]]：三种循环的适用场景
- [ ] [[break与continue]] / [[循环嵌套]]：break 只跳出一层；双重循环估算总次数
- [ ] [[数组]]：下标从 0 开始、遍历用 `i < n`、四套路默写

## 复习路线四：字符串与二维数组（Day 3）

- [ ] [[C风格字符串]]：`\0`、`%s`、读一整行
- [ ] [[C++字符串]]：`size`、`+`、`==`、`getline`
- [ ] [[二维数组]]：声明、遍历、矩阵题

## 复习路线五：函数、递归、结构体与 STL（Day 4～5）

- [ ] [[函数]]：参数、返回值、数组传参
- [ ] [[递归]]：三要素、调用栈
- [ ] [[结构体]] / [[typedef类型别名]]：定义、成员访问、结构体数组
- [ ] [[vector]] / [[pair]] / [[栈与队列]] / [[map与set]]：按场景选容器
- [ ] [[STL常用函数]] / [[迭代器]]：`sort`、`reverse`、`unique`、`lower_bound`

## 复习路线六：复杂度与二分（Day 6～7）

- [ ] [[时间复杂度入门]]：看数据范围估复杂度
- [ ] [[排序]]：`sort` 与 `cmp`
- [ ] [[二分查找]]：有序 + 单调，左闭右开模板

## 课后作业（复习题单）

### 必做

1. [P1307 数字反转](https://www.luogu.com.cn/problem/P1307)：`while` 拆位，注意负数。
2. [P5727 冰雹猜想](https://www.luogu.com.cn/problem/P5727)：`while` 模拟 + 数组保存路径。
3. [P1980 计数问题](https://www.luogu.com.cn/problem/P1980)：拆位 + 计数。
4. 小测中未 AC 的题目，合上题解重写一遍。

### 选做

- [P2141 珠心算测验](https://www.luogu.com.cn/problem/P2141)：计数数组 + 双重循环。
- [P1089 津津的储蓄计划](https://www.luogu.com.cn/problem/P1089)：模拟 + 分支边界。

### 挑战

- [P1008 三连击](https://www.luogu.com.cn/problem/P1008)：三重循环枚举。
- [P1086 花生采摘](https://www.luogu.com.cn/problem/P1086)：模拟 + 每轮找最大。
