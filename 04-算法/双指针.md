# 双指针

> [!info] 一句话
> 双指针用两个下标同向或相向移动，把 $O(n^2)$ 的枚举压成 $O(n)$——关键是让每一步移动都有明确的依据。

## 对撞指针

两个指针从数组两端向中间走，适合**有序数组**上的查找。

例：有序数组中找两个数，使它们的和等于 `target`：

```cpp
int l = 0, r = n - 1;
while (l < r) {
    int s = a[l] + a[r];
    if (s == target) {
        // 找到一组
        l++;
        r--;
    } else if (s < target) {
        l++;        // 和太小，左指针右移
    } else {
        r--;        // 和太大，右指针左移
    }
}
```

为什么能省掉一层循环？因为数组有序：`a[l]` 和 `a[r]` 的和太小，说明 `a[l]` 配当前最大的 `a[r]` 都不够，`a[l]` 可以直接排除。

P1102 A-B 数对也可以先排序，再用双指针统计差值。

## 快慢指针

两个指针同向走，`slow` 指向“已经处理好的位置”，`fast` 负责扫描。

例：有序数组原地去重：

```cpp
int slow = 0;
for (int fast = 1; fast < n; fast++) {
    if (a[fast] != a[slow]) {
        slow++;
        a[slow] = a[fast];
    }
}
int m = slow + 1;   // 去重后前 m 个元素
```

这类写法不需要额外数组，典型用途是“原地删除/移动/去重”。

## 滑动窗口（拓展）

维护一个连续区间 `[l, r]`，右端扩张、左端收缩，适合“连续子段”问题。

```cpp
int l = 0;
long long sum = 0;
int ans = n + 1;
for (int r = 0; r < n; r++) {
    sum += a[r];
    while (sum >= S) {
        ans = min(ans, r - l + 1);
        sum -= a[l];
        l++;
    }
}
```

要点：`l` 只在当前区间不满足条件时右移，保证每个元素最多进出窗口一次。

## 和二分怎么选

- 有序 + 找一个位置/答案 → 二分（见 [[二分查找]]）。
- 有序 + 从两端向中间凑 → 对撞指针。
- 连续子段 + 区间条件 → 滑动窗口。

> [!warning] 易错点
> - 对撞指针忘了先排序，移动方向就没有依据。
> - `l` / `r` 的移动条件写反。
> - 循环条件用 `l <= r` 还是 `l < r` 没想清楚，导致重复计数或越界。
> - 快慢指针的 `slow` 初值和写回位置容易差一。

> [!tip] 竞赛提示
> 看到 $n \le 10^5$ 且需要数对/子段，先想“能不能排序后双指针”；写完用暴力对拍小数据。
