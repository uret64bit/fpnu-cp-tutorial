# 回溯

> [!info] 一句话
> 回溯就是“选了就往下走，回来时把现场恢复”——DFS 在排列、组合、子集上的标准写法。

## 选与不选

回溯的核心动作只有两个：

- **做选择**：把当前元素放进答案、标记已用；
- **撤销选择**：递归返回后，把刚才的修改改回去。

为什么必须撤销？因为搜索树的不同分支共用同一份全局数组。进入分支 A 时改了 `used`，回到分叉点后如果不恢复，分支 B 就会带着 A 的“痕迹”，枚举不完整。

## 排列模板

输出 $1 \sim n$ 的全排列：每一层决定“第 `step` 个位置放哪个数”。

```cpp
int n, a[N];
bool used[N];

void dfs(int step) {
    if (step == n + 1) {           // 所有位置都填好了
        for (int i = 1; i <= n; i++) printf("%d ", a[i]);
        printf("\n");
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (used[i]) continue;     // 这个数已经用过
        used[i] = true;            // 选择
        a[step] = i;
        dfs(step + 1);
        used[i] = false;           // 撤销
    }
}
```

`used[i]` 保证同一个数不会在一个排列里出现两次。复杂度是 $O(n \cdot n!)$（$n!$ 个排列，每个输出 $n$ 个数）。

## 组合模板

从 $1 \sim n$ 里选 $r$ 个数，要求按升序输出（P1157）。和排列的区别是：**组合不关心顺序**，`1 2` 和 `2 1` 是同一组。

做法是加一个 `start`，每层只从上一个数的后面开始选：

```cpp
int n, r, a[N];

void dfs(int step, int start) {
    if (step == r + 1) {
        for (int i = 1; i <= r; i++) printf("%3d", a[i]);   // P1157 要求每数占 3 格
        printf("\n");
        return;
    }
    for (int i = start; i <= n; i++) {   // 只往后选
        a[step] = i;
        dfs(step + 1, i + 1);
    }
}
```

`start` 是“下一个数最小能选谁”。这样每个组合只会按升序被枚举一次，不会重复。

还可以加一个简单剪枝：剩下的数不够填满后面 `r - step` 个位置时直接返回，循环条件改成 `i <= n - (r - step)`。

## 子集

“选或不选”是另一种搜索树，每个元素只有两个分支：

```cpp
vector<int> chosen;

void dfs(int i) {
    if (i == n + 1) {
        for (int x : chosen) printf("%d ", x);
        printf("\n");
        return;
    }
    dfs(i + 1);                 // 不选第 i 个
    chosen.push_back(i);        // 选第 i 个
    dfs(i + 1);
    chosen.pop_back();          // 撤销
}
```

子集共有 $2^n$ 个，$n$ 超过 20 左右就要谨慎。

> [!warning] 易错点
> - **忘记撤销 `used`**：第二个排列开始全部错误。
> - **组合不设 `start`**：同一个组合按不同顺序被枚举多次。
> - **输出格式**：题目要求每行末尾有没有空格、按什么顺序输出，都要严格对齐。
> - **用 `vector` 忘记 `pop_back`**：元素越积越多，答案错乱。
> - **搜索规模过大**：$n = 20$ 的排列是 $20!$，必须剪枝或换 DP。

> [!tip] 竞赛提示
> 排列、组合、子集题，先画**决策树**：每一层在决定什么？分支有几条？什么时候到头？画清楚再套模板。八皇后（P1219）可以看成“带冲突判断的排列”，每行选一列，用 [[剪枝]] 提前排除冲突。回溯是 [[DFS搜索]] 的一种，区别只在“是否强调撤销”。
