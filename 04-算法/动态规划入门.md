# 动态规划入门

> [!info] 一句话
> DP 把大问题拆成重叠子问题，用数组记住答案——关键是状态、转移、边界三件事。

## 三要素

写 DP 之前，先回答三个问题：

1. **状态**：`dp[...]` 表示什么？把“解决到哪一步、还剩什么条件”说清楚。
2. **转移**：`dp[...]` 从哪些更小的状态来？写出递推式。
3. **初始化/边界**：最小的状态值是什么？数组下标从哪开始？

状态定义是灵魂。同一个题可以有很多种状态设计，选“好转移、好初始化”的那种。

## 数字三角形

题目（P1216）：一个数字三角形，从顶部走到底部，每次只能往左下或右下走，求经过数字之和的最大值。

```text
      7
     3 8
    8 1 0
   2 7 4 4
  4 5 2 6 5
```

**状态**：`dp[i][j]` 表示从第 `i` 行第 `j` 列出发，走到底部的最大和。

**转移**：往下走只有两个选择：

```text
dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])
```

**边界**：最后一行的 `dp[n][j] = a[n][j]`。

从下往上推，最后 `dp[1][1]` 就是答案：

```cpp
for (int j = 1; j <= n; j++) dp[n][j] = a[n][j];   // 边界
for (int i = n - 1; i >= 1; i--) {
    for (int j = 1; j <= i; j++) {
        dp[i][j] = a[i][j] + max(dp[i + 1][j], dp[i + 1][j + 1]);
    }
}
printf("%d\n", dp[1][1]);
```

为什么从下往上？因为 `dp[i][j]` 依赖下一行，倒着推时下一行已经算好了。**遍历顺序必须保证“用到的状态已经算出来”**。

## 最大子段和

题目（P1115）：求连续子段的最大和。

**状态**：`dp[i]` 表示**以第 `i` 个数结尾**的最大子段和。

**转移**：第 `i` 个数要么接在前一个子段后面，要么自己另起一段：

```text
dp[i] = max(a[i], dp[i-1] + a[i])
```

**边界**：`dp[1] = a[1]`。答案是所有 `dp[i]` 的最大值，不一定是 `dp[n]`。

```cpp
dp[1] = a[1];
int ans = dp[1];
for (int i = 2; i <= n; i++) {
    dp[i] = max(a[i], dp[i - 1] + a[i]);
    ans = max(ans, dp[i]);
}
printf("%d\n", ans);
```

这题也可以用 [[前缀和]] 里“最小前缀”的写法，两种思路等价。DP 的状态更直白，前缀和的空间更省。

## 从递归到递推

很多 DP 题最初都能写成暴力 [[递归]]：`solve(i)` 返回从状态 `i` 出发的答案，里面枚举所有转移。

如果同一个状态被重复计算，就加一个数组把答案存下来，这叫**记忆化搜索**：

```cpp
int memo[N];
bool done[N];

int solve(int i) {
    if (done[i]) return memo[i];
    // ... 递归计算 ...
    done[i] = true;
    return memo[i] = ans;
}
```

把记忆化的递归**按依赖顺序**展开成循环，就是递推 DP。二者状态和转移相同，只是写法不同：

| 写法 | 优点 | 缺点 |
| --- | --- | --- |
| 记忆化搜索 | 只算用得到的状态，边界直观 | 递归有栈开销，可能爆栈 |
| 递推 | 无递归、常数小 | 要自己排遍历顺序 |

> [!warning] 易错点
> - **状态含义没定义清**：`dp[i]` 到底表示“以 i 结尾”还是“前 i 个”，差一个字答案就错。
> - **初始化漏了**：边界值不对，后面全错；求最大值时初始化为 0 可能吞掉负数答案。
> - **遍历顺序错**：用到的状态还没算，读到 0 或垃圾值。
> - **答案位置想当然**：最大子段和的答案是 `max(dp[i])`，不是 `dp[n]`；有的题答案是 `dp[n][m]` 的某一维。
> - **数组开小/溢出**：路径方案数、和可能很大，用 `long long`。

> [!tip] 竞赛提示
> DP 的通用套路：**先写暴力递归 → 找重复状态 → 加记忆化 → 改递推 → 优化空间**。不要一上来就背模板。判断一道题是不是 DP，看两点：有没有“重叠子问题”，有没有“最优子结构”。入门题：P1216 数字三角形。下一站：[[01背包]]。
