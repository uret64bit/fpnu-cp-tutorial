# 贪心

> [!info] 一句话
> 贪心就是每一步都选当前看起来最好的——写起来短，难的是判断“局部最优”能不能推出“全局最优”。

## 什么是贪心

贪心算法在每个决策点直接选当前最优的方案，选完不回头、不反悔。

它适用的情况大致是：**当前这一步的最优选择，不会让后面失去更优的可能**。这句话不能当定理用——能不能贪，要靠证明或反例来判断。

## 排序贪心：P1223 排队接水

有 $n$ 个人排队接水，第 $i$ 个人接水要 $t_i$ 分钟。让所有人等待时间之和最小，应该按什么顺序排？

**按接水时间从小到大排**：接水快的人先接，后面等的人就少。第 $i$ 个人接水时，后面还有 $n-i$ 个人在等，所以总等待时间是：

```cpp
pair<int, int> a[N];        // (接水时间, 原始编号)
sort(a + 1, a + n + 1);     // 按接水时间升序，pair 自动比较

long long sum = 0;
for (int i = 1; i <= n; i++) {
    printf("%d ", a[i].second);
    sum += 1LL * a[i].first * (n - i);
}
printf("\n%.2f\n", (double)sum / n);
```

和可能很大，`sum` 要用 `long long`（见 [[整数溢出]]）。

## 区间调度：P1803 线段覆盖

有若干条线段，问最多能选多少条互不重叠的线段。

**按右端点从小到大排序，能选就选**：

```cpp
// 按 r 升序
sort(a + 1, a + n + 1, cmp);

int last = 0, ans = 0;
for (int i = 1; i <= n; i++) {
    if (a[i].l >= last) {   // 和已选线段不重叠
        ans++;
        last = a[i].r;
    }
}
```

直觉：越早结束，给后面留的空间越大。如果按左端点排，选了一条很长但开始很早的线段，就可能挤掉后面好几条。

## 反例意识

贪心不是“看起来对”就行。两个经典反例：

- **硬币问题**：面值 1、5、11，凑 15 元。贪心会拿 11+1+1+1+1（5 枚），但最优是 5+5+5（3 枚）。
- **0/1 背包**：按“性价比”从高到低装，可能剩下容量装不下任何物品，反而不如选总价值更低但刚好装满的组合。

所以做题时先问自己：**能不能构造一个反例？** 能构造就不能直接贪。

## 怎么确认贪心是对的

1. **交换论证**：假设最优解和贪心选择不同，把两者交换一下，说明结果不会更差。
2. **小数据验证**：写一个暴力枚举，和贪心对拍小数据（见 [[枚举]]）。

竞赛里更实际的做法：先写暴力拿部分分，再用贪心尝试；不确定就先交暴力。

> [!abstract] 拓展 · 选读
> - **邻项交换**：通过比较相邻两项的交换是否更优，推出排序关键字（P1223 的证明思路）。
> - **反悔贪心**：用优先队列把“选错的”换掉，Day 10 讲堆时会看到相关工具。

> [!warning] 易错点
> - 排序关键字选错：P1803 要按右端点，不是左端点。
> - 把“局部最优”当成“全局最优”，没有验证就交。
> - 多关键字题没想清楚第一关键字。

> [!tip] 竞赛提示
> 贪心题先想反例，再想证明；证明不出来就先写暴力。部分分也是分。
