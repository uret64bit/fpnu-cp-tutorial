# 01 背包

> [!info] 一句话
> 每件物品只有选/不选两种选择，容量有限求最大价值——01 背包。

## 问题模型

有 `n` 件物品和一个容量为 `m` 的背包。第 `i` 件物品重量 `w[i]`、价值 `v[i]`，**每件最多选一次**。求在总重量不超过 `m` 的前提下，能获得的最大价值。

“01”就是指每件物品的选择是 0（不选）或 1（选），不能选半个，也不能重复选。

## 状态与转移

**状态**：`dp[i][j]` 表示考虑前 `i` 件物品、背包容量为 `j` 时的最大价值。

**转移**：对第 `i` 件物品，只有两种选择：

- 不选：`dp[i][j] = dp[i-1][j]`；
- 选（前提 `j >= w[i]`）：`dp[i][j] = dp[i-1][j-w[i]] + v[i]`。

取较大值：

```text
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
```

**初始化**：`dp[0][j] = 0`（一件物品都没有，价值为 0）。

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 0; j <= m; j++) {
        dp[i][j] = dp[i - 1][j];                 // 不选
        if (j >= w[i]) {
            dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i]] + v[i]);   // 选
        }
    }
}
printf("%d\n", dp[n][m]);
```

二维数组直观，但空间是 $O(nm)$。注意到 `dp[i]` 只依赖 `dp[i-1]`，可以把第一维滚掉。

## 一维滚动数组

```cpp
int dp[M];   // dp[j]：容量 j 下的最大价值

for (int i = 1; i <= n; i++) {
    for (int j = m; j >= w[i]; j--) {        // 注意：倒序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
printf("%d\n", dp[m]);
```

## 为什么倒序

一维数组里，`dp[j]` 的旧值代表“前 `i-1` 件物品”的结果。更新时：

- 如果 `j` **正序**从小到大，`dp[j - w[i]]` 可能在本轮已经被第 `i` 件物品更新过，相当于第 `i` 件被选了多次——那就成了完全背包。
- 如果 `j` **倒序**从大到小，`dp[j - w[i]]` 还是上一轮的值，保证每件物品最多选一次。

一句话：**01 背包倒序，完全背包正序**。

## 初始化与变体

- **求最大价值（容量不超过 m）**：`dp` 全初始化为 0，答案是 `dp[m]`。
- **恰好装满**：`dp[0] = 0`，其余初始化为 `-INF`，最后 `dp[m]` 若为 `-INF` 说明无解。
- **求方案数**（P1164）：把 `max` 换成加法，`dp[0] = 1`：

```cpp
dp[0] = 1;
for (int i = 1; i <= n; i++) {
    for (int j = m; j >= a[i]; j--) {
        dp[j] += dp[j - a[i]];
    }
}
printf("%d\n", dp[m]);
```

方案数题同样倒序，避免同一件物品被重复计数。物品循环在外、容量循环在内，数的是**组合**（顺序不同算同一种）。

> [!warning] 易错点
> - **容量正序**：01 背包写成正序，每件物品被选了多次，答案偏大。
> - **循环边界**：`j >= w[i]`，`j - w[i]` 不能越界。
> - **初始化混用**：求最大值通常全 0；“恰好装满”才用 `-INF`，两者别混。
> - **方案数用 `max`**：方案数是累加，不是取最大。
> - **价值/方案数溢出**：和可能超过 `int`，按题目范围开 `long long`。
