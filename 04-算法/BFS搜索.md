# BFS 搜索

> [!info] 一句话
> BFS 一层一层往外扩，第一次到达就是最短步数——用队列实现。

## 队列与分层

BFS（广度优先搜索）用一个 [[栈与队列]] 的队列保存“待扩展的状态”：

- 起点入队，距离为 0；
- 每次取出队头，把它能一步到达、还没访问过的状态加入队尾；
- 队列空时，所有能到达的状态都处理完了。

因为队列是先进先出，BFS 会先处理完距离为 1 的所有状态，再处理距离为 2 的……所以第一次到达某个状态时，走的一定是**最少步数**。

## 图上的 BFS 框架

```cpp
vector<int> g[N];
int dist[N];

void bfs(int s, int n) {
    memset(dist, -1, sizeof dist);   // -1 表示没访问过
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : g[u]) {
            if (dist[v] != -1) continue;   // 已经到达过
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
}
```

结束后 `dist[v]` 就是 `s` 到 `v` 的最少边数；仍为 `-1` 说明不可达。

## 网格 BFS

迷宫、棋盘类问题把每个格子看成一个状态，四个方向是边：

```cpp
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};
int dist[N][N];
queue<pair<int, int>> q;

memset(dist, -1, sizeof dist);
dist[sx][sy] = 0;
q.push({sx, sy});

while (!q.empty()) {
    pair<int, int> p = q.front();
    q.pop();
    int x = p.first, y = p.second;
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k];
        int ny = y + dy[k];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;   // 越界
        if (a[nx][ny] == '#') continue;                       // 障碍
        if (dist[nx][ny] != -1) continue;                     // 已到达
        dist[nx][ny] = dist[x][y] + 1;
        q.push({nx, ny});
    }
}
```

马的走法（P1443）只是把方向数组换成 8 个“日”字方向；电梯（P1135）把楼层当点，边是 `+K[i]`、`-K[i]`。

## 入队即标记

BFS 最容易错的地方是**标记时机**：

- 正确：发现一个没访问过的邻居，**立刻**设 `dist` 并标记，再入队；
- 错误：等出队时才标记。同一个状态可能被多个邻居同时发现，重复入队，队列膨胀，答案也可能被覆盖。

```cpp
if (dist[v] != -1) continue;
dist[v] = dist[u] + 1;   // 入队前就标记
q.push(v);
```

## DFS 与 BFS 怎么选

| 需求 | 选择 | 原因 |
| --- | --- | --- |
| 枚举所有方案、排列组合 | [[DFS搜索]] + [[回溯]] | 需要走到底再撤销 |
| 判断能不能到达、数连通块 | DFS 或 BFS | 都行，DFS 代码短 |
| 最少步数、最少操作 | **BFS** | 分层扩展，第一次到达即最短 |
| 状态数很大但答案浅 | BFS | 不用走完整棵搜索树 |

> [!abstract] 拓展 · 选读
> **多源 BFS**：如果同时有多个起点，把所有起点先入队、距离都设为 0，再统一 BFS。这样一次就能求出每个状态到**最近**起点的距离，不必对每个起点各跑一遍。典型应用：多个火源同时蔓延、多个商店求最近距离。

> [!warning] 易错点
> - **标记太晚**：出队才标记，导致重复入队，严重时 MLE。
> - **`dist` 没初始化**：`-1` 表示未访问，忘了 `memset` 会把 0 当成“已访问”。
> - **方向数组写错**：马走日、八个方向的坐标要成对检查。
> - **队列没清空**：多组数据复用同一个队列，必须确保上一组已经 `while` 弹空。
> - **求最短路径却用了 DFS**：DFS 第一次到终点不保证最短。

> [!tip] 竞赛提示
> 看到“最少”“最短”“最快”先想 BFS；看到“所有方案”“能不能到”再想 DFS。写 BFS 前先把**状态**定义清楚：状态里要放哪些信息？一步转移有哪些？状态会不会重复？这三点决定代码结构。入门题：P1443 马的遍历、P1135 奇怪的电梯。
