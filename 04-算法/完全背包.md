# 完全背包

> [!abstract] 拓展 · 选读
> 01 背包的变体：每件物品可以选无限次。前置：[[01背包]]、[[动态规划入门]]。

> [!info] 一句话
> 每件物品可以选无限次——把 01 背包的容量循环改成正序即可。

## 与 01 背包的区别

| | 01 背包 | 完全背包 |
| --- | --- | --- |
| 每件物品可选次数 | 最多 1 次 | 无限次 |
| 一维容量循环 | 倒序 `m → w[i]` | 正序 `w[i] → m` |
| 复杂度 | $O(nm)$ | $O(nm)$ |

题目说“每种物品有无限个”“可以重复购买/采摘”，就是完全背包。

## 正序循环

```cpp
long long dp[M];   // P1616 的价值和会超过 int

for (int i = 1; i <= n; i++) {
    for (int j = w[i]; j <= m; j++) {        // 注意：正序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
printf("%lld\n", dp[m]);
```

和 [[01背包]] 的一维写法只差循环方向：`j` 从 `w[i]` 到 `m`。

## 为什么正序

正序时，`dp[j - w[i]]` 在这一轮已经可能被第 `i` 件物品更新过：

```text
dp[j] ← dp[j - w[i]] + v[i]
         ↑ 可能已经包含若干个第 i 件物品
```

于是“再选一次第 `i` 件”被允许，正好对应无限次选择。倒序则保证每次用的是上一轮的值，每件只能选一次。

也可以从“选了之后还能再选”的角度理解：正序让同一件物品的影响像涟漪一样往后传递。

## 初始化

和 01 背包一致：

- 求最大价值（容量不超过 `m`）：`dp` 全 0；
- 恰好装满：`dp[0] = 0`，其余 `-INF`；
- 方案数：`dp[0] = 1`，转移用加法。

> [!warning] 易错点
> - **正序/倒序混用**：完全背包写成倒序，每件物品只能选一次，答案偏小。
> - **价值溢出**：P1616 的价值和可能很大，`dp` 用 `long long`。
> - **初始化照搬错**：“恰好装满”和“不超过容量”的初始化不同。
> - **把完全背包当 01 背包做**：看到“无限个”还倒序，直接 WA。

> [!tip] 竞赛提示
> 看到“每种物品无限个”“可以重复选”就是完全背包；看到“每件只有一个”就是 01 背包。两者的代码只差循环方向，但**背后的状态含义不同**，考试时先想清楚再写。入门题：P1616 疯狂的采药。
