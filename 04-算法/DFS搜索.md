# DFS 搜索

> [!info] 一句话
> DFS 一条路走到黑，走不动再回头——适合“枚举所有可能/判断能不能到”。

## 搜索树与调用栈

DFS（深度优先搜索）本质上是**带“撤销”的递归枚举**。把每一步的选择画成一棵**搜索树**：

- 当前这一层做一个决策（往哪个方向走、选不选这个数）；
- 进入下一层继续决策；
- 走到死路或终点就返回，返回前把这一层做过的修改恢复原状。

递归的调用栈自动帮我们记住“来时的路”，所以写起来就是普通的 [[递归]]。

## 网格 DFS 框架

以走迷宫为例：从 `(x, y)` 出发，每次走上下左右一格，不能出界、不能碰障碍、不能走回头路。

```cpp
const int N = 10;
int n, m, sx, sy, ex, ey, ans;
int dx[4] = {0, 0, 1, -1};   // 右、左、下、上
int dy[4] = {1, -1, 0, 0};
bool vis[N][N], ok[N][N];    // ok 表示这一格能不能走

void dfs(int x, int y) {
    if (x == ex && y == ey) {   // 到达终点
        ans++;
        return;
    }
    for (int k = 0; k < 4; k++) {
        int nx = x + dx[k];
        int ny = y + dy[k];
        if (nx < 1 || nx > n || ny < 1 || ny > m) continue;   // 越界
        if (!ok[nx][ny] || vis[nx][ny]) continue;             // 障碍或走过
        vis[nx][ny] = true;        // 标记
        dfs(nx, ny);               // 进入下一层
        vis[nx][ny] = false;       // 撤销，换一条路
    }
}

// 调用前别忘了标记起点
vis[sx][sy] = true;
dfs(sx, sy);
```

这份框架能数出**所有**从起点到终点的路径（P1605 迷宫）。如果只问“能不能到”，可以不用撤销，`vis` 标记一次就够。

## 边界与标记

DFS 写错，十有八九错在这四件事：

1. **起点标记**：`dfs(sx, sy)` 之前把起点设为已访问，否则可能绕回起点。
2. **越界判断**：先判断 `nx/ny` 在范围内，再访问数组。
3. **障碍与已访问**：两个条件都要查，顺序无所谓，但不能漏。
4. **撤销时机**：`vis` 在递归调用之后恢复，保证“下一条路径”还能走这一格。

如果是**连通性**问题（比如数连通块），走过就永远标记，不需要撤销——撤销反而会重复搜索。

> [!warning] 易错点
> - **忘记撤销**：求所有路径时，上一分支的标记留到了下一分支，答案变少。
> - **起点没标记**：路径可能反复经过起点，甚至死循环。
> - **方向数组写错**：`dx` 和 `dy` 配错，走到斜角或原地不动。
> - **递归太深**：网格 $10^5 \times 10^5$ 或链状图，递归深度过大直接爆栈（RE）。
> - **死循环**：有环图忘记 `vis`，或者只标记不撤销/只撤销不标记。

> [!tip] 竞赛提示
> DFS 适合“**找所有解**”“**判断能不能到**”“**枚举所有方案**”。如果题目问“最少几步/最短路径”，优先想 [[BFS搜索]]——DFS 找到的第一条路不一定最短。搜索前先估复杂度：状态数 × 每个状态的转移数，超过 $10^7$ 就要考虑 [[剪枝]] 或换算法。
