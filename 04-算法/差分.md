# 差分

> [!info] 一句话
> 差分是前缀和的逆运算：区间加变成两个单点修改，最后扫一遍前缀和还原。

## 差分数组

定义：

```cpp
d[i] = a[i] - a[i - 1];    // 约定 a[0] = 0
```

也就是说，`a` 是 `d` 的前缀和。区间修改在差分数组里只影响两个位置。

## 区间加

把 `a[l]` 到 `a[r]` 全部加上 `x`：

```cpp
d[l] += x;
d[r + 1] -= x;      // 数组要开到 n + 2
```

- `d[l] += x`：从 `l` 开始，后面的前缀和都多了 `x`；
- `d[r + 1] -= x`：从 `r + 1` 开始把多出来的 `x` 抵消掉。

## 还原

所有修改做完后，对 `d` 求一次前缀和，就得到修改后的 `a`：

```cpp
for (int i = 1; i <= n; i++) {
    d[i] += d[i - 1];
    printf("%lld ", d[i]);
}
```

## 与前缀和的关系

| 操作 | 工具 |
| --- | --- |
| 多次区间查询 | 前缀和 |
| 多次区间修改，最后统一查询 | 差分 |

两者互为逆运算：**加 → 差分，查 → 前缀和**。

> [!abstract] 拓展 · 选读
> **二维差分**：给子矩阵加 `x`，在四个角打标记；最后做二维前缀和还原。了解概念即可，不要求默写。

> [!warning] 易错点
> - `r + 1` 越界：数组至少开到 `n + 2`。
> - 修改完忘记做前缀和还原。
> - 多次修改和最终答案可能很大，用 `long long`。
> - 多组数据要清空差分数组。
