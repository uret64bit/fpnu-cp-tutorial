# 模拟

> [!info] 一句话
> 模拟题没有巧妙算法——题目怎么说，你就怎么写；难的不是思路，是"不漏细节"。

## 什么是模拟

把题面描述的过程一步一步翻译成代码。比如 P1328 生活大爆炸版石头剪刀布：两个人各有自己的出拳周期表，每一轮同时出一拳、按规则比大小记分——规则全在题面里，照抄成循环即可。

## 常见类型

- **日期 / 时间类**：换算、累加、跨天跨月（如 P1425 小鱼的游泳时间）；
- **矩阵 / 网格类**：按走向填充、按规则翻格子（如 P5731 蛇形方阵）；
- **规则类**：题面给一张对局表 / 状态表，照表执行（如 P1328）；
- **格式输出类**：把算出来的东西按古怪的格式打印（如 P1067 多项式输出）。

## 怎么写好模拟

1. 先在草稿纸上列**状态表**：整个过程需要记住哪些变量？——分数、当前周期下标、当前坐标、上一步的值……
2. 把主流程写成 `[1] [2] [3]` 的文字步骤，再逐条翻译成代码；
3. 重复出现的片段抽成 [[函数]]（比如"算出某人这一轮出什么"）；
4. 先让样例跑对，再回头抠边界。

## 易错点

> [!warning] 模拟的四个大坑
> - **边界**：第 0 天、只剩 1 张牌、坐标为 0 时……样例往往测不到；
> - **更新顺序**：先用旧值把所有该算的算完，再统一更新状态——边算边改，很容易用上"已经改过"的值；
> - **循环次数差一**：从 0 还是从 1 开始、到 `< n` 还是 `<= n`；
> - **输出格式**：多余空格、少换行、末尾不能多空格——评测对格式是逐字节比的。

> [!tip] 竞赛提示
> 模拟题是"细心分"：样例过了不算完，自己再造两组边界数据手算核对；最后把题目从头再读一遍，逐个条件对照代码。
