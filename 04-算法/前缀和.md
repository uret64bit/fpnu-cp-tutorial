# 前缀和

> [!info] 一句话
> 前缀和把“每次重新求和”变成“一次预处理 + 一次减法”：区间和 = 两个前缀和相减。

## 暴力与预处理

如果题目要回答 $m$ 次“区间 $[l, r]$ 的和”：

- 每次循环扫一遍：单次 $O(n)$，总共 $O(nm)$，$n, m \le 10^5$ 时必然超时。
- 预处理前缀和：预处理 $O(n)$，每次查询 $O(1)$。

## 一维前缀和

用 1-based 下标最省心：

```cpp
long long sum[N];       // sum[i] = a[1] + ... + a[i]
sum[0] = 0;
for (int i = 1; i <= n; i++) {
    scanf("%lld", &a[i]);
    sum[i] = sum[i - 1] + a[i];
}

// 区间 [l, r] 的和
long long ans = sum[r] - sum[l - 1];
```

为什么是 `sum[l - 1]`？因为 `sum[r]` 包含 `a[1]` 到 `a[r]`，要减掉 `a[1]` 到 `a[l-1]`。

## 最大子段和：P1115

求连续子段的最大和，可以维护“当前前缀 - 之前的最小前缀”：

```cpp
long long sum = 0, mn = 0, ans = LLONG_MIN;
for (int i = 1; i <= n; i++) {
    sum += a[i];
    ans = max(ans, sum - mn);   // 以 i 结尾的最大子段和
    mn = min(mn, sum);          // 维护最小前缀
}
```

注意 `ans` 要初始化为 `LLONG_MIN`，因为答案可能是负数。

> [!abstract] 拓展 · 选读
> **二维前缀和**：`s[i][j]` 表示左上角 `(1,1)` 到 `(i,j)` 的矩形和：
>
> ```cpp
> s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];
> ```
>
> 子矩阵 `(x1,y1)` 到 `(x2,y2)` 的和用容斥：
>
> ```cpp
> s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
> ```

> [!warning] 易错点
> - 忘记 `sum[0] = 0`，或下标从 0 开始却按 1-based 写。
> - 答案可能超过 `int`，前缀和数组用 `long long`。
> - 区间端点写错：`sum[r] - sum[l]` 会把 `a[l]` 也减掉。

> [!tip] 竞赛提示
> 看到“多次区间求和”先想前缀和；看到“多次区间修改”先想 [[差分]]。二维题先确认数据范围，再决定用不用二维前缀和。
