# 迭代器

> [!info] 一句话
> 迭代器是容器的"通用指针"：`begin()` / `end()` 标出一对左闭右开区间，`sort`、`reverse`、`lower_bound` 只认这种区间，所以同一份算法能用在数组、`string`、`vector` 上。

## 从哪里来

数组排序写的是两个指针：

```cpp
sort(a, a + n);      // 区间 [a, a + n)
```

`string` / `vector` 不能写 `s, s + n`，于是容器自己提供一对迭代器：

```cpp
sort(v.begin(), v.end());
reverse(s.begin(), s.end());
```

- `begin()`：第一个元素的位置；
- `end()`：最后一个元素的**下一个**位置（越界位置，不是最后一个元素）。

这和 `a` / `a + n` 完全对应，所以区间永远是左闭右开 `[begin, end)`。空容器 `begin() == end()`，循环天然一次也不进。

## 基本用法

```cpp
vector<int> v = {10, 20, 30};
for (vector<int>::iterator it = v.begin(); it != v.end(); ++it) {
    printf("%d ", *it);
}
```

三个动作和指针一样：`*it` 取值、`++it` 走到下一个、`it != v.end()` 判断到头。

平时不用写这么长：类型交给 `auto`，或者直接用范围 for：

```cpp
for (auto it = v.begin(); it != v.end(); ++it) ...
for (int x : v) ...        // 范围 for 本质就是迭代器遍历
```

## 竞赛里用到的三种场合

### 1. 给算法传区间

```cpp
sort(v.begin(), v.end());
int m = unique(v.begin(), v.end()) - v.begin();   // 迭代器相减 = 距离 = 个数
v.erase(unique(v.begin(), v.end()), v.end());      // 真正删掉多余元素（了解）
```

### 2. 查位置

```cpp
int pos = lower_bound(v.begin(), v.end(), x) - v.begin();
```

`map` / `set` 要查位置用成员函数 `mp.lower_bound(x)`（$O(\log n)$）；不要套全局 `lower_bound`，在这种结构上会退化成 $O(n)$。

### 3. 遍历 / 边遍历边删

```cpp
for (auto &p : mp) printf("%d %d\n", p.first, p.second);   // 以键、值都是 int 为例

for (auto it = st.begin(); it != st.end(); ) {
    if (要删) it = st.erase(it);   // erase 返回下一个位置
    else ++it;
}
```

## 不是所有迭代器都能做加减法

| 容器 | 迭代器能力 | `it - begin()`、`it + 1` |
| --- | --- | --- |
| 数组 / `vector` / `string` | 随机访问 | 可以 |
| `map` / `set` / `list` | 只能 `++` / `--` | 不行 |

> [!warning] 易错点
> - `v.end()` 不是最后一个元素，`*v.end()` 是错的；
> - 迭代器和下标不能混用：`sort(v.begin(), v.size())` 编译不过；
> - 容器改变（`erase`、`insert`、扩容）后，之前存的迭代器可能失效，别存着跨操作再用；
> - 迭代器要解引用才能当值：`printf("%d", it)` 错，`printf("%d", *it)` 对。

> [!tip] 竞赛提示
> 日常解题很少显式写迭代器：传区间用 `.begin()` / `.end()`，遍历用范围 for；要下标就 `it - v.begin()`（仅随机访问容器可以）。
